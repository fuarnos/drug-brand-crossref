## 4. 教训

- 半成品代码在 build 窗口里**只应存在于 agent 自己的工作区状态**；一旦人喊停，必须把 `site/build.py` 恢复 HEAD 并撤回 CHANGELOG 版本节，否则任何后续误构建会把旧功能标成新版本。
- 版本号只认 CHANGELOG 第一节——「先写 CHANGELOG 再改代码」的流程在中断时反而制造风险，下次可改为「代码完成 → 写 CHANGELOG → build」。
