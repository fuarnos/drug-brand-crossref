## 改了什么

### 1. `deploy/i18n_check.py`：`LANGS` 加 fr + 扁平表归一化

fr 在 `site/build.py` 里**不是** `{"fr": {...}}` 那一层，而是两张扁平表（键就是 i18n key）：

- `FR_I18N`（主表＋一次 `FR_I18N.update({...})`）
- `FR_PREP_KEYS`（覆盖页 / About 的 FR 专用文案）

所以只把 fr 塞进 `LANGS` 会让 18 张字典全报「缺 fr」。本次在**读取层**做归一化，不动 build.py：

| 新增 / 改动 | 作用 |
|---|---|
| `load_fr_flat()` | AST 取 `FR_I18N` + `FR_I18N.update({...})` + `FR_PREP_KEYS`，顺序与 build.py 合并顺序一致（后写的覆盖先写的） |
| `normalize_fr()` | 扁平表按 **en 键反查** → 每张字典的 `fr` 子表；扁平表里 en 没有的键记 `orphans`（本次 0 个） |
| `effective_i18n(..., fr_flat)` | 复刻 build.py `_merge_static_i18n()` 的 fr 装法：键集 = en，没译文的键回落英文；`fallback["fr"]` 记下全部回落键 |
| `_live_langs()` | 读 `data/languages.json` 判断 fr 是否已上线（现为 `enabled: true`），只在已上线时并入 FR 专用键（与 build.py 同条件） |

fr 的判定口径（写进脚本 docstring）：

- **键集**：fr 子表多出 en 没有的 key → FAIL（拼错 / 陈旧）；合并后 fr 键集与 en 不一致 → FAIL（构建期 `_assert_i18n_complete()` 同一条硬拦）。
- **伪翻译**：有法语译文、值与 en 一模一样 → 按白名单判 FAIL / WARN。13 条「法语里就是这么写」的登记进新白名单 `PSEUDO_OK_KEYS_FR`（逐条理由见下），其余照旧 FAIL。
- **缺译**：键在、法语译文没有（构建期静默回落英文）→ **不静默**：逐字典覆盖率 + 全部回落键写进 `stats.fr_coverage`，摘要打一行 INFO。`FR_FALLBACK_BLOCKS = True` 即升级为 FAIL（留给译文补齐后切换）。
- **release notes**：`RELEASE_LATE_LANGS = {"fr": "v0.11.5"}` —— fr 只从最新版起强制，历史 57 版不补，汇总成一条 INFO。
- **模板直接引用**：`I18N["fr"]["x"]` 也纳入「key 是否存在」检查。
- **术语**：`data/label_translations.csv` 没有 fr 列 → fr 的剂型译名比对**未覆盖**，以 INFO 明示（不算通过）。

`--self-test` 追加 10 项 fr 断言（归一化 / 多余键 FAIL / 缺译不 FAIL 且进 fallback / 同形白名单 / release notes 五语与历史豁免），共 **28 项全过**。
顺带修了自检的环境依赖：原来用系统 `tempfile.TemporaryDirectory`，在 Windows 沙箱下 `mkdtemp` 的 0o700 DACL 会 `WinError 5`，改成仓库内 `.tmp/i18n-selftest/`（gitignore）。

## fr 同形白名单（13 条，逐条理由）

法语与英语拼写完全相同的词，值 == en 属正常，登记后走 INFO 而不是 FAIL（`PSEUDO_OK_KEYS_FR`）：

| key | 值 | 理由 |
|---|---|---|
| `home.ca` / `home.fr` | Canada / France | 国家名在法语同形（与 `home.cn` / `home.au` / `home.hk` 的 es 白名单同例） |
| `nav.sections` | Sections | 法语 section 的复数 |
| `nav.menu` | Menu | Menu 在法语同形 |
| `report.field_page` / `res.col_link` | Page | Page 在法语同形（页面标题 / 表格列名） |
| `a1.source` / `maker.source` | Source | Source 在法语同形 |
| `home.suggestions` / `ac.suggestions` | Suggestions | Suggestions 在法语同形 |
| `form.inhalation` / `form.effervescent` / `form.solution` | inhalation / effervescent / solution | 法语剂型名沿用拉丁词根，与英语同形（术语表暂无 fr 列，无对照可查） |

未登记的同形词仍会 FAIL（自检里用 `nav.new_stub`="Menu" 验证过），白名单不能拿来盖真缺译。
其余 6 条 fr 同值走的是**原有**白名单：`parse.match.nickname`(alias)、`parse.match.pinyin`、`release.none`(—)、`unit.mci`(mCi)、`atc.label`(ATC)、`form.injection`(术语表专有名词) —— 合计 19 条 fr 同值，**全 INFO、0 FAIL 0 WARN**。
