## 3. 风险 / 已知问题

1. **xz 覆盖率受数据层限制**：127,085 条索引里 65,075 条有中文名；DB `inn_zh` 约 2,879/12,649（high+medium apply 后），
   因此 zh 界面里仍会出现部分英文/盐型中文（如 Aspirin 无中文、Caffeine 回退到盐型「枸橼酸咖啡因」）。这是逐段回退，
   不是前端 bug；补齐需继续跑 inn_zh 回填（P2 数据任务）。
2. **体积接近守卫**：dist **395.4 MB**（v0.5.4 390.1 → +5.3 MB，主要是 `index.json +2.3 MB` 与 8 个副本、What's new 三语正文）；
   v0.5.5 发布后若再加字段需复测 400 MB 软上限。
3. **What's new en/es 是 AI 机器翻译**：数据 `machine_translated: true`，页面已三语标注「AI 翻译，中文原文为准」；
   正式对外前建议人工过一遍（尤其数字/药名/监管实体）。
4. **静态副本与根页内容重复**：已用 canonical + hreflang 指向各语言版本，SEO 上应无重复内容惩罚；但副本内导航仍回根页
   （语言由 localStorage 保持），如要求“副本内导航也留在 /es/”需再改 nav 链接（可 P2 做）。
5. **title/meta 运行时切换**依赖 i18n.js；静态副本已写死对应语言，根页首屏（JS 前）显示英文 title，JS 执行后切换。
6. **`docs/…` 相对链接**：CHANGELOG 里的 `docs/许可清单.md` 等在站点产物中不存在，本次统一改到 GitHub blob
   （`_md_inline`）；若还有其他相对链接指向仓库文件，同样会被改写（当前只匹配 `docs/` 前缀）。
7. **sitemap/页数变化**：本次 DB 并发更新导致 drug/combo 页数比 v0.5.4 少 132/48 页，发布时以新构建为准。
