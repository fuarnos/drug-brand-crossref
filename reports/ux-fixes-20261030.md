## 0. 结论

## 1. P0-1 身份混排（同成分表混入不同复方）

**复现**：搜「泰诺」，「同成分的其他商品」出现单方氯苯那敏、右美沙芬+愈创甘油醚、羟考酮+对乙酰氨基酚。

**修复**（`site/build.py` APP_JS）：
- 锚定精确命中条目的 substance 集合；「同成分」只收**成分集合完全相同**的条目。
- 共享部分成分但集合不同的，另立「**含相同成分之一（不是同一复方）**」区块，文案明确 `不是同一种产品`。
- 两个区块前固定「同名或同成分，都不代表可以互换」警示。
- 回归检查（DOM dump）：搜「泰诺」时「同成分」只剩 4 成分复方（对乙酰氨基酚+伪麻黄碱+右美沙芬+氯苯那敏）；单方对乙酰氨基酚等进入「含相同成分之一」区块，不再混入。

## 2. P0-2 品牌查询看不到品牌/计数口径不一致

**复现**：搜「泰诺」主表两行「无商品名」，组头却写「1/2 个品牌」。

**修复**：
- 无商品名行显示「无商品名」角标 **+ 「命中名：<搜索词>」**（不再只显示无商品名）。
- 组头计数改为 **「N 条记录」**（`res.records_noun`），不再把记录数叫品牌数。
- 结果区加「N 条记录没有商品名，按名称层展示」脚注；无商品名不再与品牌同权重。
- DOM 证据：`命中名: 泰诺`、`3 个名字命中`、`... 条记录` 均出现；移动截图 `.tmp/ux-after/m-search-tainuo.png` 首屏可见。

## 3. P0-3 移动端首屏无反馈

**复现**：390×844 引导卡 482px，结果区 y≈935；零结果同样在首屏外。

**修复**：
- 输入/搜索一开始就自动收起「三步看懂」（并写入现有 `u1.dismiss.v1`）。
- 结果计数/加载态/零结果 `#meta` 移到搜索框正下方（`.search-status`），不再等滚过引导卡。
- `startSearch()` 在索引加载前显示「正在加载检索分片…」。
- 结果区仍保留空态/错误重试；零结果文案在首屏可见。

**验证**：390×844 截图首屏直接看到「3 个名字命中」和首条结果；`#meta` 在 DOM 中位于 `#out` 前。

## 4. P0-4 矩阵/筛选器

**复现**：桌面「筛选」按钮点击无变化；默认只显示 CN/GB 或 US/GB/CN 不说；清空国家只剩规格列无提示；「重置」是最大绿色按钮。

**修复**：
- 桌面 CSS 隐藏无效「筛选」按钮（面板常显）；移动端保留真正的展开/收起。
- 摘要常显 **「7 / 7 行 · 市场 3/10」**；「全部市场」按钮保留。
- 清空全部国家时摘要改为 **「至少选择一个市场才会显示列」** 并加 `role=status`，不再静默。
- 「重置」文案改「恢复默认 / Restore defaults / Restaurar valores / 回復預設」，保留次级样式。
- 服务端先渲染默认 3 列并加 `data-defcol`，CSS 首屏隐藏其余列；JS 读取服务端默认列，避免加载后改列造成 CLS。
- 移动端矩阵仍为卡片布局；滚动提示四语。

**验证**：DOM dump `mf-count = 7 / 7 行 · 市场 3/10`；默认列 `data-defcol=1` 24 处（8 行 × 3 列）；`matrix.au_note` 存在。
