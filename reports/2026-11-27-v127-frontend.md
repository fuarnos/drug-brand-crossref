## 3. 外部方案检索（按 AGENTS.md 附二，`DISABLE_TELEMETRY=1`）

命令：`& $node vendor\modern-web-guidance\skills\modern-web-guidance\modern-web.mjs search|retrieve "<topic>"`

| 候选（vendored 指南） | 关键结论 | 是否采用 |
|---|---|---|
| `forms` | **DO** 把 `<label>` 放在输入框之前、视觉上叠在控件上方（更快扫读）；标签与输入间距小于组间距；**DON'T** 用 `aria-label`/`aria-labelledby` 覆盖可见 label | **采用**：hero 增加可见 `<label for="q">`，并删掉 WIP 的 `aria-labelledby="h1"`（否则可访问名变成页面标题） |
| `navbar` | 响应式导航不要在窄屏硬编码断点；**DO NOT** 用 `<details>/<summary>` 做站内导航（部分读屏把 summary 读成 "summary"/"disclosure triangle"，语义不一致）；当前页用 `aria-current="page"` | **部分采用**：三链接按「一行放不下就换行」的 flex-wrap 处理（窄屏整行、触控 44px），不引入脚本断点。`<details>` 语言下拉**本版不动**（全站既有壳、200k+ 页共享；换 button+popover 需要改全站壳与 CSS，属单独版本，建议登记为后续项） |
| `viewport-aware-dropdowns` | 浮层跟随触发器用 CSS Anchor Positioning 最省 JS，但浏览器支持仍属 Limited（Chrome 157 / Safari 27，Firefox 不支持）；Popover API 虽已 Baseline（2025-01-27），light-dismiss 在旧浏览器仍需 polyfill（`@oddbird/popover-polyfill`，需特性检测后再加载） | **不采用**：本仓无 npm / 静态内联构建，为语言下拉引入 polyfill 会让每个长尾页多一个请求；`.sn-panel` 现有「视口内钳制 + 可滚动」已满足 `--float-*` token 的溢出约束，本版只调页头排布 |

结论：H2 的布局/表单细节按 `forms` 的「可见 label + 前置」落地；导航用原生 flex + 无脚本断点，符合 `navbar` 的「不要硬编码断点」；浮层重写（popover/anchor positioning）不在本版范围，也未引入新依赖。
