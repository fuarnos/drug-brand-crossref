## 1. 三个根因与改法

| 现象（改前） | 根因 | 改法（改后） |
|---|---|---|
| `Mounjaro ×14` / HK `×72` | 倍数取的是「名称变体行数」（`product_name JOIN name_variant`） | 按**记录（pid）数**：MX `×1` 不渲染、HK `×72 → ×6` |
| `1 个记录 · 0 个厂家` | 厂家数只数「无商品名」桶（`k_mah = len(mahs)`） | 块内 **distinct MAH**：MX / EU / HK 都显示 1 个厂家 |
| `展示 0 个，共 0 个` | `n_head` 只数有结构化规格的行 | 新模板 `drug.spec_count_und`：`0 个已展示 · N 条未公开规格`（`data-und`，五语） |

- 五语键：`drug.spec_count_und`（en / es / zh / zh-Hant / fr 齐，构建期 `_assert_i18n_complete()` 658 键 × 5 语言通过）。
- 4 处会重写块头的 JS 都补了 `{u}` 替换：`i18n.js apply()` / `initListView` / `initListFilters` / `boot.js _mkblock_js` → 切语言、点剂型 chip、输入规格筛选后都不露占位符。
