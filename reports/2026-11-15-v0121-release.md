## 1. L7 页头四件套（10 类页面）

`_page_head(prefix, title_html, summary_key, crumb, search)` + `_search_form()`，接入：成分页 / 商品名页 / 复方页 / 厂商页 / 分类页 / ATC 索引 / 覆盖页 / 关于 / 警示 / 易混淆。

- 结构固定：**返回路径 → h1 → 一句话摘要（≤1 行）→ 继续搜索**。
- 页头搜索框搬进 `<main>`，`boot.js` 用 `main .page-search` 判断去重 → **全站仍只有一个搜索框**（避免长尾页两个搜索框）。
- 验收（工位 A12 断言，390 + 1440 两档）：**6/6 类**「返回链接 ≥1 + main 内搜索存在」全部成立；`h1 ~ p.sub` 摘要行数从 drug **6** → ≤2。
