## 1. 改了什么（单文件 `site/build.py`，+181 / −34 行）

### ① Q13 数量单复数（en / es / zh / zh-Hant / fr）

**做法：构建期选键，不动前端模板机制。** 服务端本来就知道两个计数（`n_rec` 记录数、`k_mah` 厂家数），
所以在拼 HTML 时直接选「单数键 / 复数键」，沿用现有 `_lang_block_text(key, **fmt)` 与
`data-i18n-tpl` 的「键 + {占位符}」机制 —— 切语言、筛选时前端只替换数字，无需新语法。

新增键（每语 5 个，共 25 条文案）：

| key | en |
|---|---|
| `drug.undisclosed_n_one` | `1 record · {k} manufacturers` |
| `drug.undisclosed_k_one` | `{n} records · 1 manufacturer` |
| `drug.undisclosed_nk_one` | `1 record · 1 manufacturer` |
| `drug.und_more_one` | `and {n} more (1 manufacturer)` |
| `drug.spec_count_und_one` | `{shown} shown · 1 record without a stated strength` |

- 选择逻辑抽成 `_und_count_key(n_rec, k_mah)`（docstring 写清「只有等于 1 才走单数，0 与 ≥2 走复数」）。
- 块头模板：`_spec_tpl = "drug.spec_count_und_one" if n_rec == 1 else "drug.spec_count_und"`。
- **附带修了一个既有缺口**：这几个块走 `_lang_block_text()`，而它原来只渲染 en/es/zh/zh-Hant
  四个语言块 → **法语界面这块是空白**（`_lang_blocks` 只显示与当前语言相同的那块）。
  现在按 `I18N_REQUIRED_LANGS` 追加已上线语言（fr），否则 Q13 的「五语」无从谈起。

### ③ Q4 coverage@768 首屏条目（纯 CSS + 少量属性，无新依赖）

产物的关键结构约束：这张表**同时挂着 `table.res` 和 `table.coverage-table`**，
全局手机规则 `table.res tr{display:block}` / `table.res td{display:block}` 同特异性且写在后面 ——
第一版用 `table.coverage-table tr{display:grid}` 被它盖掉（网格没生效，390 仍是 1.5 条），
改成 **`#covtable` 前缀**（id 特异性更高）后生效。

| 断点 | 改法 |
|---|---|
| ≤767px（卡片式） | 一行一个字段 → **两列网格**（市场名占满一行、6 个字段两两并排、缺口占满一行截断 1 行）；`td` 改 `display:flex`，标签 `::before` 可缩可省略号、**数值 16px 不截断**（宁可截标签）；两列百分比格的括号绝对数在手机隐藏，**保留在 `title` 里**；`tr` 上下 margin/padding 收紧 |
| 768–1023px（表格） | `table-layout:fixed` + 按列给宽度（缺口列 25%）、`th` 14px / `td` **16px**（第一版写 15px，触发「正文 ≥16px」全局阈值，已改）、缺口最多 2 行 |
| ≤1279px | 缺口格 `.covgap` 两行截断，全文进 `title`（≥1280 不截断，桌面不受影响） |

顺带修的两处（都在同一模板，属 Q4 落地必需）：
- **手机卡片标签一直是英文**（中文界面也写 `Market`）：给 7 个 `<td>` 挂 `data-i18n-label="coverage.col.*"`，
  复用既有的 `[data-i18n-label]` 机制；长标签列（映射 / 规格 / 同步 / 截止）再挂 `data-label-short`
  （新增 4 键 × 5 语），手机只显示短标签，避免把数值挤掉。
- 缺口格加 `.covgap` 包装 + `title` 全文（原来这类 `.covgap` 规则是**没有任何元素命中**的死样式）。
