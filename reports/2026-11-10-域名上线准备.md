## 3. 阻塞点：用户要做的 3 件事（agent 代替不了）

1. **注册 Cloudflare 账号**（邮箱验证）+ 绑定支付方式（R2 免费层也要绑卡）。
2. **在 Cloudflare Registrar 购买 `drugcrossref.com`**（约 $10.44/年，国际信用卡；若无国际卡，改在阿里云/腾讯云注册后把 NS 改到 Cloudflare，多一步实名）。
3. **建 R2 bucket + API token**，把 4 行写进仓库根 `.env`（已 gitignore，**不要发对话**）：

   ```
   R2_ACCOUNT_ID=...
   R2_ACCESS_KEY_ID=...
   R2_SECRET_ACCESS_KEY=...
   R2_BUCKET=drug-brand-crossref
   ```

## 5. 风险与红线
