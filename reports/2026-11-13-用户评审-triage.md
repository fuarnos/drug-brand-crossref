# 用户评审 triage（2026-11-13，v0.11.5 线上页面）

> 来源：用户对 v0.11.5 线上 6 类页面的实际查看（首页 / Tylenol 搜索结果 / 成分页 / 品牌页 / 退烧止痛分类页 / 覆盖说明页），桌面端代表性页面。
> 本文只做三件事：**把用户观察逐条复核**（复现 / 未复现，附 SQL 口径）、**给根因假设**、**排下一版去向**。不改代码、不发版。
> 结论先行：**6 类问题里 5 类已用现查数据/产物复现**（含 499.9996 mg 与 960 mg/30 mL 两个硬数据问题）；FR「250 mg 下出现 1000 mg」用精确 SQL 未复现（口径见 §1.4），但同类风险真实存在 → 立项通用检查。

## 1. 逐条复核

### 1.1 Tylenol Extra Strength 被汇总成「500 mg / 960 mg · 片剂」，展开含液体/粉末 —— ✅ 复现（分组键缺剂型/释放/体积关系）

- 现查：`name_key` = `tylenol extra strength` 在库有 **26 个产品**（全 US），其中 8 个抽样产品均为 `form_base=tablet`、`acetaminophen 500 mg`（`US-50090-1695` 等）。
- 但同品牌组里另有 **`US-50580-187`（tylenol extra strength）**：`acetaminophen 960 mg / 30 mL`、`form_base=liquid`（见 §1.2）。搜索/品牌页把「品牌名相同」的产品放在同一组，组头却取单一剂型 `片剂` + 拼接强度 `500 mg / 960 mg`，于是「片剂」标签代表了一个液体记录。
- 根因假设：构建期分组键 = 品牌/名称 + （部分）强度，**未把 `form_base`/`release`/`per_volume` 纳入组头语义**；组头只在有多值时拼接强度、剂型取第一个/多数值。
- 去向：**P0**（T10）分组键改为「完整成分组合 + 剂型 + 规格 + 释放方式」，品牌名只作上层容器；组头禁止用单一剂型覆盖多剂型（多于一种时显示「片剂 / 液体」或「多剂型」）。

### 1.2 「960 mg 30 mL」在详情出现、品牌页缩成「960 mg」 —— ✅ 复现（per_volume 未显示）

- 现查 `product_component`：`strength_value=960 且 per_volume_value=30` **2 行**：
  - `US-50580-187`（acetaminophen / tylenol extra strength，960 mg / 30 mL）
  - `CN-XN02BED158X00-c4f48346`（对乙酰氨基酚口服溶液 / 泰诺林，960 mg / 30 mL）
- 全库 `per_volume_value=30` 共 **1,722 行**——「每 X mL 含 Y mg」的关系普遍存在，不能只显示 `Y mg`。
- 根因假设：品牌页/详情模板取 `strength_value + strength_unit` 后就结束，没有拼 `per_volume_value + per_volume_unit`；也没区分「每片含量 / 液体浓度 / 包装总量」。
- 去向：**P0**（T10）统一规格渲染：`960 mg/30 mL` 保留；包装总量单列（pack）；三处（搜索组头 / 详情 / 品牌页）同一函数。

### 1.3 成分页「325 mg 片剂」分组混入复方 —— ✅ 复现（成分页按强度分组，未按成分集合分支）

- 现象与用户描述一致：成分页的国家/规格分组里，同一强度下既有单方也有「名称里明确含其他成分」的复方；页面没有「仅含此成分」与「含此成分的复方」的区分。
- 根因假设：成分页按 `(strength, form)` 聚合，未用「component 集合是否恰为该成分」二分；复方也没有列出全部活性成分与各自含量。
- 去向：**P0**（T10）成分页分组先分「仅含此成分 / 含此成分的复方」，复方行显示全部成分+各自剂量；「同类 ≠ 可互换」提示保留。

### 1.4 法国分组「250 mg 片剂」下出现名称含「1000 mg」的产品 —— ⚠️ 未复现（精确 SQL 0 命中，保留通用检查）

- 现查：`country='FR'`、`form_base='tablet'`、存在 `strength_value=250`、名称去空格后含 `1000` → **0 行**（`1 000`/`1000` 两种写法都试过）；放宽到任意剂型也 0 行。
- 可能解释：用户看到的是「名称里的 1000 UI」（如 `cadelius 1000 ui comprime`、`demilos 1000 ui comprime`）与「250 mg」分组在视觉上同屏，或来自另一个市场列；截图未留，暂标「待复核」。
- 但 AU 已确认同类硬问题（§1.5），且「名称 vs 结构化规格」冲突是系统性风险 → **仍立项**（T15 构建期冲突检查 + T10 冲突显示「规格待核实」），不因单条未复现放弃。

### 1.5 出现 499.9996 mg —— ✅ 复现（41 个 AU 组件，浮点/单位换算）

- 现查：`ABS(strength_value-500) < 0.01 且 ≠500` 共 **41 个 component**，全部 AU：`500.0082`、`500.0081`、`500.0003`、`499.9996`…（TGA ARTG 的 g↔mg 换算）。
- 全库「非整数强度」97,169 行里绝大多数是合法值（12.5 mg、0.375 mg…），不能一刀切取整。
- 去向：**P0**（T10）显示层规则：仅在「接近常用整数且偏差 ≤ 容差」时归整显示（如 499.9996 → 500 mg），**原始值入库/数据包保留**；规则写死、可解释、可抽检；数据层不批量改（T15 只出清单）。

### 1.6 品牌页：无中文名 / 标题与提示矛盾 / 「碰撞」术语 / 泰诺泰诺林重复 —— ✅ 复现（渲染口径与文案问题）

- `substance` 里 `acetaminophen` 有 `inn_zh`（对乙酰氨基酚），但品牌页把 `name.no_zh`（**名称**无中文）徽标贴在了**成分**旁 → 与搜索页/成分页矛盾。
- 品牌页标题用 `fam.title`=「同一品牌在其他市场的写法」，下方 `fam.warn`=「同名不同药」——用户会把品牌关系误读成翻译关系。
- 「三家不同成分，属严重碰撞」是内部术语（collision 视图分级），不该直接给用户看。
- `name_variant` 抽 `tylenol extra strength` 有 6 条（大小写/空格/来源不同）；中文「泰诺/泰诺林」重复显示待按「原文=译文自动去重 + 语言/来源去重」处理。
- 去向：**P1**（T12）品牌页改「相关品牌名称与配方差异」表格（市场 / 注册名 / 完整成分 / 关系说明）；徽标只看成分自己的中文名；共享一套中文名映射；去掉内部术语。

## 5. 证据与复现命令

- 复现脚本（只读）：`.tmp/probe_review.py`、`probe_review2.py`（`sqlite3 file:data/drugs.db?mode=ro`）。
- 关键 SQL：
  - `SELECT COUNT(*) FROM product_component WHERE strength_value=960 AND per_volume_value=30;` → 2
  - `SELECT COUNT(*) FROM product_component WHERE strength_value IS NOT NULL AND ABS(strength_value-500)<0.01 AND strength_value<>500;` → 41
  - `SELECT COUNT(*) FROM product_component WHERE per_volume_value=30;` → 1,722
  - `SELECT COUNT(*) FROM substance WHERE lower(inn_en) LIKE '%acetaminophen%';` → `acetaminophen`（有 `inn_zh`）
- 页面：`/index.html?q=Tylenol`、`/drug/acetaminophen.html`、`/name/tylenol-extra-strength.html`、`/coverage.html`。
