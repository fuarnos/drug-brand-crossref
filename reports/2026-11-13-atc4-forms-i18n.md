## 2. 改动（`site/build.py`，4 处，均带 `v0.11.4 task-63` 注释）

### 2.1 chips 标签：客户端按剂型码取字典（静态 0 增量）

`initListView()` 里新增 `labelChips()`：按 `data-form-filter` 的剂型码取
`drug.forms_all` / `form.<code>` / `atc4.form_other`，**只改标签文本节点**（`.n` 里的计数不动），
并把 `nav#forms` 的 `aria-label` 同步成 `drug.forms_label`。注册进 `__DSH_APPLY_HOOKS`，
`apply()` 每次跑（含切语言、`?lang=` 补载）都重写一次 → 即时生效。

```js
var key = k ? (k === 'other' ? 'atc4.form_other' : 'form.' + k) : 'drug.forms_all';
var v = window.T(key);
if(!v || v === key) return;          // 字典缺键 → 保留服务端英文，不渲染 key 字面量
for(var i = 0; i < chip.childNodes.length; i++){
  var nd = chip.childNodes[i];
  if(nd.nodeType === 3 && (nd.nodeValue || '').trim()){ nd.nodeValue = v + ' '; break; }
}
```

> **为什么不用 `data-i18n` 包一层**：第一版就是那样写的，功能也对（四语全过），但每页 +427 B
> （10 个 chip × ~42 B）→ 全站 **+5.3 MB**。v0.11.4 总量已到 937.8 MB、离 900 MiB 软上限只剩
> ~5.6 MiB（见 §6），所以改成客户端改写：静态 HTML 与 v0.11.3 逐字节相同（`formchips` 块
> `1,032 B → 1,032 B`，实测），无 JS 时仍是英文兜底。

### 2.2 统计摘要 / 身份行：千分位

```python
-                    f'<b>{n_markets}</b> <span data-i18n="drug.markets">markets</span> · '
-                    f'<b>{n_records}</b> <span data-i18n="drug.records">records</span></p>')
+                    f'<b>{n_markets:,}</b> … <b>{n_records:,}</b> …'
-  <span class="ds-meta">{n_markets} … {n_records} …</span>
+  <span class="ds-meta">{n_markets:,} … {n_records:,} …</span>
```

### 2.3 中文成分名（`inn_zh`）：有才显示，不硬翻

- 服务端：仅当该成分 `inn_zh` 含 CJK 时，在 h1 下的 `.drug-name-src` 副行渲染
  `<span class="name-zh" data-inn-zh hidden style="display:none">对乙酰氨基酚</span>`
  （12,637 个成分里 **3,103 个有中文名**，覆盖率 24.6%；`acetaminophen → 对乙酰氨基酚`）。
- 客户端：`i18n.js` 新增 `applyInnZh()`，只在 `zh` / `zh-Hant` 打开，其余语言 `display:none`。
  用 inline style 而不是只靠 `[hidden]`——作者样式会打败 `[hidden]`（v0.11.2 踩过）。
- h1 保持英文（原名/SEO/首屏不变），中文名以副行呈现，符合「中文 + 原文」且不动 h1 排版。

### 2.4 ATC4 明细表：切语言后重绘

`ATC4_JS` 末尾补一个 `__DSH_APPLY_HOOKS`：`details` 打开且数据已缓存时按当前语言重绘表头/
剂型列（`cache` 已存，不会重复 fetch）。

## 5. 已知缺口（如实记）

1. **繁体界面的中文名显示简体源**（`对乙酰氨基酚`，不是 `對乙醯氨基酚`）：数据里只有简体 `inn_zh`，
   按数据纪律不硬转；如果以后要繁体名，应该进数据层（`substance` 加 zh_hant 列或术语表），不在前端转。
2. **h1 仍是英文**（`Acetaminophen`），中文名在副行。理由：h1 同时喂 JSON-LD / 页面标题 / 首屏排版，
   改 h1 要另做产品决策；本轮按「不动 h1、加副行」交付。
3. **ATC 成员列表的中文名**（`.atcmembers li .nm`、`data-nl` 徽章体系）本轮没动 —— 那是另一套
   「双语名 + 缺名徽章」逻辑，不属于本次剂型区。
4. chips 的英文静态文案与计数仍是服务端输出：**无 JS 用户**（极少数）看到英文，与已发布行为一致。
5. 未跑 `first_screen_check`（本轮只动副行与 chips，未改 h1/首屏结构；如需要请 Lead 在发布构建上统一跑）。
