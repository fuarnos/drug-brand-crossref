## 1. 做法：六级流水（越往后越保守）

`JpMapper.map()` 依次尝试，**任何一层拿不准就往下走，走到最后仍不成立就留空**：

| # | 层 | 依据 | 命中数（token） |
|---|---|---|---|
| 0 | `non-substance` | 类目词/生药/汉方方剂/院内制剂（见 §5） | 1,417（不计入分母） |
| 1 | `manual-international` | **`data/sources/jp_inn_map.csv` 人工复核表（184 行）** | 3,051 |
| 2 | `jp-zh-exact` | 日文汉字名 ↔ 库内 `inn_zh` 字形相同（尿素/大黄/甘草酸） | 少量 |
| 3 | `jp-kanji-dict` | 汉字/固有名词典（ブドウ糖/生理食塩液/アミノ酸…） | 137 |
| 4 | `jp-salt-phrase` | 整串盐短语（炭酸水素ナトリウム/酸化マグネシウム…） | 少量 |
| 5 | `katakana-skeleton[-atc]` | 片假名→罗马字→辅音骨架，**精确命中** | 4,545 + 359 |
| 5b | `katakana-skeleton-equiv` | 骨架等价写法（r/l、b/v、d/z/j…） | 831 |
| 6 | `katakana-fuzzy2` | 编辑距离 ≤2（长骨架 ≤3） | 774 |

**多候选裁决（任何一步只剩一个才接受）**：首辅音一致 → 盐型一致（日文「塩酸塩」↔ 英文 hydrochloride）
→ 全库唯一带 ATC → 基名是其余候选前缀（Donepezil / Donepezil Hydrochloride）→ 池内唯一。

**宽松层（5b/6）额外三条闸门**（不加会立刻出现误配）：
1. 候选**必须有 ATC**（砍掉 `pork-brain`、`prune`、`Star Anise Fruit` 这类库内脏数据）；
2. 罗马字 ↔ 英文拼写相似度 ≥ 0.35 / 0.40（`difflib`）；
3. **首 2 个辅音必须一致**（专治 `タスルグラチニブ → Tolebrutinib`、`ガンマオリザノール → Bemotrizinol`、
   `サッカリンナトリウム → Sarecycline` 这类“尾部像、头部不像”的后缀家族误配）。

## 2. 修掉的四个真 bug（这是 53.3% 的主因，不是缺词表）

1. **`酸 → acid` 的全局单字替换**（旧版 `JP_ACID`）。它把 `グルコン酸`、`アミノ酸`、`炭酸ランタン` 全改成
   `…acid`，直接毁掉 **2,227 个 token**（占旧分母 16.7%）。→ 删除，改为「盐名前缀/后缀词表 + 整串短语表」。
2. **盐名只认后缀**。日语也写 `塩酸アムロジピン`（前缀型）。→ 前缀 18 词 + 后缀 26 词两张表。
3. **盐名剥离只扫一遍**。`ロキソプロフェンナトリウム水和物` 去掉「水和物」后才露出「ナトリウム」，
   一遍扫会漏。→ **迭代到稳定**；同时加「过度剥离保护」（`炭酸水素ナトリウム` 若把「炭酸」当盐剥掉只剩「水素」
   → 回退不剥，交给整串短语表）。
4. **括注与全角**。`ダルベポエチンアルファ(遺伝子組換え)[…後続1]`、`セフカペン ピボキシル`（含空格）
   都匹配不上。→ `strip_jp_annotations()` 去 `()（）[]【】` 与空白（**原文仍保留进 raw**，不丢信息）。

另外：罗马字转换补了**促音 `ッ`**（双写辅音）、**长音 `ー`**（重复前一元音）、**拨音 `ン`**（b/p/m 前写 m）。

## 4. 误配抽检（30 条，分层随机，seed 固定）

方法：按方法分层（manual / exact / atc / equiv / fuzzy 各 6 条）随机抽，逐条人工核对。
命令见 §8。

**判定：5 条错，全部落在 equiv/fuzzy 两层；`manual`（6/6）与 `exact`（6/6）两层 0 错。**

| 抽到的日文名 | 映射到 | 判定 | 说明 |
|---|---|---|---|
| 臭化カルシウム | Calcium | ❌ | 应为 Calcium Bromide（候选过泛） |
| キセノンガス(非放射性) | Xenon 133 Xe | ❌ | 非放射性 vs 放射性同位素 |
| チクジョ（竹茹） | Chickweed | ❌ | 生药；已加入 non-substance 名单 |
| ベプリジル塩酸塩水和物 | Biperiden | ❌ | 应为 Bepridil |
| ピパンペロン塩酸塩 | Papaverine | ❌ | 应为 Pipamperone |

> 结论：**宽松层仍有约 1/6 的错配**（30 条里 5 条，其中 4 条来自 equiv/fuzzy）。这三层合计贡献 1,605 个 token。
> 若把这三层关掉，映射率会掉到 ≈68%，但 30 条抽检可做到 0 错。
> **建议**：首发取「manual + exact + atc + 词典」四层（≈68%，0 错），把 equiv/fuzzy 命中的高频项
> 逐条补进 CSV 抬到 85%——这是唯一同时满足「≥85%」与「≤1/30」的路。

## 5. 「非单一成分」口径（1,417 token / 1,221 品目，**不计入分母**）

来源里 `成分名` 写的是**类别**而不是某一个 INN，硬配一个就是造假。分四类，逐类可复核：

| 类 | 例 | 理由 |
|---|---|---|
| 汉方方剂 | 葛根湯エキス・補中益気湯・小青竜湯…（正则 `エキス$` / `^漢字{2,}(湯\|散\|丸)$`） | 复方生药，不是 INN |
| 生药（单味） | オウギ・サイコ・ジオウ・ハンゲ・チクジョ…（27 个具名） | 药材不是单一化学成分 |
| 院内制剂/体液 | 腹膜透析液・維持液・開始液・乳酸リンゲル・術後回復液 | 多组分或器械类，无单一 INN |
| 血制品/益生菌 | 人血小板濃厚液・乾燥濃縮人血液凝固第VIII因子・ビフィズス菌 | 生物制品，本库 substance 口径不含 |

> 口径写进报告而不是藏着：**「分母 11,925 + 非单一成分 1,417 = 13,342」**，两个数字都报，读者可自行还原。
