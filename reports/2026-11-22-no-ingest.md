## 3 建模与字段映射（`etl/ingest_no.py`）

FEST 的 `LegemiddelMerkevare` 已经是「商品名 + 剂型 + 含量 + 成分」这一身份，`Legemiddelpakning` 是它的包装规格。按本站 L2 判定键（国家 × 剂型 × 规格 × 活性成分）：

- **一行 product = 一个品牌条目**（8,985），`product_id = NO-<商品名 slug>-<品牌 Id sha1 前 8 位>`（重跑稳定，不随包装增删变化）；
- **包装规格聚合进 `product.pack`**（8,985/8,985；1,345 个品牌有多包装，按 `Pakningsstr + EnhetPakning` 去重后用 ` · ` 连接，最长截断 600 字符）；
- **状态只能由包装级日期聚合**：全部包装 `AvregDato` → `withdrawn`；全部包装 `MidlUtgattDato` → `discontinued`；至少一个包装无标记 → `active`；品牌无包装 → `unknown`。`status_date` 取下线日期最大值。
- **两处与评估报告不同、已按实测更正**：
  1. `KatVirkestoff` 里同时放 `Virkestoff`（成分主档）与 `VirkestoffMedStyrke`（成分+含量），**没有** `KatVirkestoffMedStyrke` 这一层；
  2. `Markedsforingsinfo/VarenrUtgaende` **不是**下线标记——它的文本是**另一个订货号**（实测：包装 Varenr=577074 的 VarenrUtgaende=119988），是「新旧订货号」替换链接。因此状态只认 `AvregDato` / `MidlUtgattDato`；若把 `VarenrUtgaende` 当标记，会多判约 200 个品牌停售（本轮不采用）。
- 引用解析（实测 100% 可解析）：`Pakningsinfo/RefLegemiddelMerkevare` → 品牌内层 Id（10,964/10,964）；`SortertVirkestoffMedStyrke/RefVirkestoffMedStyrke` → `VirkestoffMedStyrke/Id`；`VirkestoffMedStyrke/RefVirkestoff` 与 `SortertVirkestoffUtenStyrke/RefVirkestoff` → `Virkestoff/Id`（684/684）。

## 11 已知缺口（页面口径必须写清）

1. **无注册号**：FEST 不含 MT 号；`approval_id` 全空，**不能做「按注册号查挪威」**。订货号 `Varenr`、条码 `Ean` 不是注册号，未入库。
2. **只有活动条目**：8,985 个品牌的 `Status` 全为 `A / Aktiv oppføring`，FEST 不导出历史/停售全量。品牌级状态只能由包装日期聚合（本轮 8,778 active / 175 discontinued / 32 withdrawn），页面应写「FEST 收录的处方链条目」而不是「挪威全部上市药品」或「在售清单」。
3. 36 条顺势疗法条目只有类别词（`Homeopatic composed/singel drug`），无成分 → 无 `product_component`，`note` 已说明。
4. 3 条形制未归类（`Munnhulepose`×2、`Matriks til vevslim`），`form_base='other'`；16 条途径原文为「未指定」，`route=NULL`。
5. 648 个成分行无含量（276 个品牌仅成分名，FEST 本身无 `VirkestoffMedStyrke`）；含量单位里的生物制品单位（`RI`/`E`/`SQ-E`/`DAgE`/`CCID50`/`HEP`…）原样保留，不做换算。
6. 每剂/每 mL 分母含挪威语单位（`penn` 105 / `sprøyte` 212 / `dose` 267 / `flaske` 50 …），只在体积/质量单位上归一到 `mL`/`L`/`g`/`mg`，其余原样。
7. `VarenrUtgaende` 语义更正（见 §3）：若后续页面文案沿用评估报告「订货号停用=下线标记」的说法，需要改。
8. 碰撞 +425 severe 属既有成分主档拆分问题（见 §9），页面会出现若干「同名不同药」警示；不是本次 NO 数据错误。
9. 未做：价格、SmPC 正文、`Refusjon`（报销）、`Interaksjon`（相互作用）、挪威语界面（`markets.json` 的 `ui_language_gaps` 已由 frontend 声明）。
