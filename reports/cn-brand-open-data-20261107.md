## 0. 结论（先看这三行）

1. **没有找到「CC0/CC-BY + 中文商品名 + 可批量下载」的数据集**。6 类候选逐个查过：唯一开放许可的（Wikidata CC0）条目极少；其余要么无开放许可（NMPA / 省级挂网 / 说明书站）、要么根本没有商品名（WHO INN）、要么是爬商业库且无许可的二手数据（GitHub/NMPA 转储）。
2. **可落地只有 2 个**：① **省级医保局挂网/集采目录（季度增量策展）**——已验证，预计最多 **+200～2,000 个批文（0.3–3pp）**；② **Wikidata CC0**——唯一可自由再发布，但预计只有 **约 15–20 条商品名**（多为台/港用字），外加 100+ 条中文通用名可作交叉校验。
3. **缺口仍补不满**：CN 现查 **126,716 个产品（87.4%）** 无商品名、**60,854 个批文**无商品名；开放渠道的上限远低于此。要进一步，只能靠 NMPA 人工/浏览器限速通道（top-N 通用名）或**在途的上海医保局政府信息公开答复**（法定 2026-11-26 前）。

## 3. 逐类取证

### 3.1 ① NMPA（国家药监局）

- **批量下载/开放接口：无**。`/datasearch/home-index.html` 本轮复测 **HTTP 412**（WAF，与 `reports/cn-brand-expand.md` 的 4/4 被拦一致）；旧接口 `app1.nmpa.gov.cn` 此前不可达。
- **字段确实含「商品名」**（国产药品数据库），这是缺口最直接的官方来源，但只支持单条查询。
- **许可**：站点声明页 412 不可读，`docs/许可清单.md` 结论仍是「未找到再发布许可」；按 🔴 只能存事实字段 + 链原文。
- **人工通道估算**（沿用 `reports/cn-brand-channels.md`）：≥3s/请求、只 top 500–1,000 通用名约 **1–2 小时**（估计能补 **300–800 条品牌名**，需人工核对）；全量 60,854 批文 ≈ **51 小时**，不建议。**禁止**绕 WAF/验证码。

### 3.2 ② 省级挂网/集采目录（可落地）

- 本地已有抽样：`data/raw/cn_provinces/` **24 个 PDF**（北京 105 页挂网目录、江苏 11 批公布表、青海 2 个、浙江 OSS 附件、福建/湖南/吉林等）。
- **46%（11/24）的文件有「商品名」列**；解析 2,729 行 → 325 品牌行 → **236 个品牌 DB 已有 → 71 条新候选**（`data/cn_brand_candidates.csv`：江苏 49 / 北京 19 / 青海 2 / 浙江 1）。
- **许可**：政府公开信息，**无开放许可**。现有做法（`reports/cn-brand-expand.md` §4）：只发布事实字段（商品名/通用名/批文/企业）+ 署名「省级医保局挂网目录」+ 来源 URL + 抓取日期，**不转载原表/PDF**，可应要求撤下。
- **难点**：天津 403、上海 403、贵州 418、广西连接重置、山东需人工导出；PDF 表格结构各省不一；江苏表**无批准文号**（只能用通用名+企业匹配，confidence=medium）。

### 3.3 ③ WHO / 世界银行 / OKF

- **WHO INN**：`docs/许可清单.md` §3 已定 **CC BY-NC-SA 3.0 IGO**（ICG 条款）——非商业 + 相同方式共享；且只给 INN 名（拉丁/英/法/西），**没有任何商品名**，也基本没有中文。
- **世界银行开放数据**：只有宏观经济/卫生支出指标，无药品名称层。
- **OKF（Open Knowledge Foundation）**：无中文药品命名数据集。
- 结论：与「补 CN 商品名」无关；NC/SA 还会污染「可再发布」口径。

### 3.5 ⑤ Wikidata（可落地，CC0）

- 许可：**CC0 1.0**（`docs/许可清单.md` 已登记 `wikidata` / `wikidata_atc_p267`），可自由再发布，署名为礼貌而非义务。
- 实测（SPARQL，2026-11-07）：
  - `P31=Q28885102`（pharmaceutical product）**2,925** 条 → **28 条有中文标签**（品牌/制剂为主：泰诺、可他敏、開瑞坦、利他林、來適泄、麻卡因、馬利蘭、專注達、補佳樂、胃仙U…）。
  - 合并 `P31=Q12140`（medication）后：**186 条有中文名**（medication 158 / 药制品 24 / 两者兼具 4），其中 21 条带活性成分（P3781）。
  - 与本地库比对：**15 条**中文名 = 本地 `substance.inn_zh`（通用名，不是商品名）；**18 条**已在 `name_key`/俗称里；**168 条**本地没有——但绝大多数是**中文 INN（单抗/酶）或疫苗名**（门冬酰胺酶、埃万妥单抗、辉瑞-BioNTech 疫苗…），不是中国商品名。
  - 真正可用作「商品名」的：**约 15–20 条**，且多为**台/港用字**（阿斯匹靈、開瑞坦、來適泄），与大陆商品名不完全一致。
- 对齐方式：条目多数带 `P3781`（活性成分）/ `P267`（ATC）→ 可与现有 `substance` 直接对齐；无 P3781 的按英文 label 模糊匹配并人工确认。
- **没有**「批准文号（批准文号）」属性（`wbsearchentities` 查「批准文号」→ 0 条）→ Wikidata **无法**把品牌挂到具体批文，只能挂到成分层。

## 7. 风险与边界

1. **许可**：本任务推荐的两个渠道都是「事实字段」口径；省级挂网**无开放许可**，页面/About 必须署名并可撤下，**不得**发布原 PDF/原表。Wikidata 为 CC0，仍需署名（可追溯）。
2. **预期管理**：即使把省级挂网全量策展，也只能从 12.1% → 15% 左右（0.3–3pp）；**六成以上的无商品名批文很可能本来就没有商品名**（官方表登记为「无」）——这不是「没抓到」，而是「不存在」，页面上应继续显示「无商品名」。
3. **数据质量**：挂网目录品牌名常与企业名/系列名混；同名不同企业合法；只按批文挂接，不合并产品（沿用三条底线）。
4. **不可程序化**：NMPA 412 已多次复现，**不再尝试**；任何「绕 WAF/验证码」都不做。
5. **Wikidata 覆盖陷阱**：186 条中文名看起来不少，但品牌级只有 ~28，其余是中文 INN/疫苗名；若直接把中文 INN 当商品名入库会污染品牌层，必须过滤（脚本已给 `is_substance_inn_zh` / `in_db_name_key` 两个标记）。
6. **时点**：上海信息公开答复（11-12 / 11-26）可能一次性改变结论；到期后应重评本报告 §4。
