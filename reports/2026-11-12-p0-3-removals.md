## 1. 独立复核：方法与被验证的结论

### 1.1 白名单（与 P0-3 的黑名单口径独立）

先定义「一个合法的中文药名/俗称长什么样」，不满足才进嫌疑集：

| 维度 | 白名单条件 |
|---|---|
| 字符集 | 汉字 / 拉丁字母（含重音）/ 数字 / 空格 / `·` `-` `/` |
| 长度 | 汉字 ≤10；纯拉丁 ≤24 字符 |
| 禁字 | `是 为 和 或 与 及 啥 都 了`；`的`（但 `的松` 放行：强的松/考的松）；`吗`（但 `吗啡/吗叮/吗啉/吗喃` 放行） |
| 禁词 | 宣传/生产/厂家/厂商/商品/药品/说明/注意/可以/可能/收载/曾用名/误导/音译/通用名/别名/别称/名称/俗称/简称/而来/多为/多个/不一样/常为/通常为/常见/类药/分别/包括 |
| 尾缀 | 片/胶囊/注射液/口服液/颗粒/乳膏/软膏/滴眼液/糖浆/栓/丸 |

### 1.2 对账（旧 45 行 vs 独立 66 嫌疑）

| 项 | 数值 | 说明 |
|---|---|---|
| 独立重扫嫌疑 | **66** | 白名单不通过 |
| 旧删除 / 旧改写 | 45 / 6 | P0-3 报告口径 |
| 旧清单被独立口径覆盖 | **45 / 45** | 42 条白名单直接命中 + 3 条人工兜底（`不同`/`之一`/`别被`） |

```python

    """SELECT substance_id, alias FROM alias_all
       WHERE substance_id IS NOT NULL ORDER BY alias_id"""

    nicknames.setdefault(sid, []).append(alias)

# site/build.py:8705-8709  —— 全量拼串：有 esc()，没有过滤、没有条数上限
```
