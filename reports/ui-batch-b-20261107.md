## 6. 已知缺口

1. 移动端「⋯」菜单里的语言链接由静态 `?lang=` 生成；根页切换语言后下拉标签（`🌐 中文/EN`）不会即时更新（副本页按语言构建正确）。
2. `aria-current` 在构建期按页面语言标注；客户端切换语言后由 i18n.js 更新 `.on` 类，但 `aria-current` 不随动（可在 v0.10.1 补 JS）。
3. 首页 HTML 仍未回到 v0.9.7 的 ±5%（225,950 vs 205,734 = +9.8%），本次只保证 ≤227.3 KB；要真正 −5% 需拆 CSS/i18n（建议 v0.10.1）。
4. 结果页「紧凑视图」依赖 localStorage，无 JS 时保持舒适密度（优雅降级）。
5. 未跑 Lighthouse / 未上真机；桌面截图 620px 并排是便于对照的缩放，不是 1:1。
6. 未写 `site/dist`、未 commit、未发布；`.tmp/build-uiB` 为候选产物，等待 lead 发 v0.10.0。
