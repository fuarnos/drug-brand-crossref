## 2. 方法纠正：差异比对必须用内容哈希（**教训**）

**v0.10.2 的 r3**（`.st-badge .mk` 11→12 px）我报告「只有 `assets/style.css` 变了，其余 121,315 文件字节完全相同」。
那次比对用的是 **`stat().st_size`**：`12px → 13px`、`14px → 16px`、`line-height:18px → 20px` 这类改动**字节数不变**，
同长度的内容变化会被整批漏掉；而且当时 `BUILD_V` 也变了（`BUILD_V = sha1(build.py + 两份 zh-hant 字典)`，改 CSS 必然换值），
**全站 HTML 的 `?v=` 都变了**，按体积比对完全看不出来。

**v0.10.3 终版**改用内容 sha1 逐文件比对，真实差异是：

| 类别 | 文件数 | 内容 |
|---|---:|---|
| HTML 仅 `?v=` 变化 | 112,668 | `BUILD_V 4121363165 → 4059119559`；逐字符核 `coverage.html` 22,651 字符中**只差 19 个字符**，全在两个 `?v=` 的尾数里；`404.html`（不带 `?v=`）**字节完全相同**（反证） |
| 真正的 CSS | 1 | `assets/style.css` |
| 文案（四语发布说明） | 4 | `whats-new.html` + `es/` + `zh/` + `zh-hant/` |
| 数据派生 | 1 | `data/idx/atc4-forms.json`：rows 28,378 → 28,733、`generated_at 2026-10-30 → 2026-11-09`（数据窗口重生 `data/sources/atc4_forms_20261031.json`） |

**规则（写给以后）**：
1. 差异范围一律 `sha1(内容)` 比对，不写「字节数相同 ⇒ 无差异」；
2. 涉及 `site/build.py` 的改动必然改 `BUILD_V`，**预期全站 HTML 都差 19 个字符**，这不是回归；
3. 报告差异时给出「机制 + 反证」（例如 `404.html` 无 `?v=` 却不差）。

## 5. 构建期 bug（`py_compile` 抓不到的那类）

`+N` 的 checkbox id 用了函数里不存在的 `sid`（`NameError`）。`py_compile` 通过、`--fast` 通过，
只有真正渲染 12 万页时才炸。**是靠本地「单函数 harness」**（`_drug_list_html()` 直接喂合成数据 → 写 HTML → 真浏览器量行高）**先抓到**的。

规则：**动渲染函数就要真跑一次渲染**；`python -m py_compile` 只能证明语法，不能证明函数体内引用的名字存在。
