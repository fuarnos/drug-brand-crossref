## 1. T16：品牌页释放结论（`site/build.py`，169 增 / 15 删）

**根因**（比任务描述更深一层）：`product.release='none'` 表示「来源未记录」，占全库 **94.4%**；`collision` 视图按
`COUNT(DISTINCT release)>1` 分级把 `none` 也算一种值 → 925 个 `warning` 名字里 **850 个其实是「1 种已知释放方式 + 其余未标注」**，
页面过去把它固定渲染成「Different release — not interchangeable」。泰诺林那行就是 `{}` 与 `{ER}` 的比较。

**改法**：`RELEASE_UNKNOWN={'none',''}`、`_release_unrecorded()`、`_key_release_locked()`（== 1 种已知码且无未标注）；
`_family_relation()` 只在两侧都 locked 时才给 `fam.rel.release`，否则 `fam.rel.multi`（≥2 种已知码）或 `fam.rel.multi_unknown`；
`severe` 条纹一字未动；同源两处同步收紧（结果行徽标、T11 `?pick=&pmk=` 对照行）。四语 + fr 新增 7 键（五语各 622 键同集）。

**构建产物实测**（Lead 抽检，命令见 §5）：

| 指标 | before（v0.11.7） | after（v0.11.8） |
|---|---|---|
| 名字页旧结论 `Different release — not interchangeable` | 925 处（按 key 计） | **0 页**（`data-i18n="name.warning"` 命中 0） |
| 名字页「释放方式未逐条记录」`name.rel_unknown_title` | 0 | **697 页** |
| 名字页「多种释放方式」`name.rel_multi_title` | 0 | **73 页** |
| 品牌对照表 `fam.rel.release`（「释放机制不同，不可互换」） | 2 行 | **0 行**（泰诺林行 → `fam.rel.multi_unknown`） |
| `severe`（同名不同药）条纹 | 25,088 key | 不变（`alcohol` / `sodium-fluoride` 页逐字节一致） |
| 检索结果行「释放机制不同」徽标 | 925 条 | **75 条**（真有 ≥2 种已知码才贴） |
| T11 对照框「释放」行 | 品牌汇总后 `a===b` 判 same/diff | 两侧各锁定 1 种才判，否则「选择具体产品」（Node 直测上线 JS 5/5 PASS） |

> 口径说明（site-ui 报告 §4 已写）：850/75 是 **key 级**统计（含 `inn` 型 key 与无页 key）；**页面级**实测是 697 + 73 = 770 页。
> 三种页面文案按真实记录状况选：「多种释放方式」/「释放方式未逐条记录」/ 不出条纹，避免把「1 种已知 + 未标注」说成「多种」。

## 2. T17：成分中文名去盐型名（DB 单写窗口）

**现查基线**：3,103 个有中文名的成分里，779 个（25.1%）中文名含盐型词；其中 542 个所在成分**根本没有盐型 variant**（明确错用）。

**做法**（`etl/apply_inn_zh.py` 新增 4 个模式，原「只填空值」保护逻辑未改）：宽口径 47 词系扫出 **1,117** 行 → 只做字符串剥离（不翻译）→
过 5 道闸门（长度 / 结尾词 / 金属离子 / 与另一成分撞名 / 残形仍是盐型词）→ **可修正 339 行**（high 235 / medium 104），
**丢弃 778 行并分类计数**（`inn_en` 本身是中文 621 / 剥不动 71 / 成分本身就是盐 65 / 人工决定不剥 7 / 残形仍有盐型词 6 / 过短 3 / 撞名 3 / 酯名 1 / 残形仍是盐型词 1）。

| 项 | before | after |
|---|---|---|
| `substance.inn_zh` 非空 | 3,103 | 3,103（只改名不删名） |
| 含「盐酸」/「枸橼酸」/「钠」结尾 | 264 / 24 / 174 | **110 / 16 / 116** |
| `nickname`（其中 `kind=misnomer`） | 57 | **396**（+339） |
| `product` / `product_component` / `variant` | 494,992 / 650,358 / 14,244 | **完全不变** |
| 重复中文名组数 | 14 | 14（没造出撞名） |

用户原始用例（`/drug/acetaminophen.html` 复方行，构建后实测）：`Caffeine 咖啡因 65 mg`（原「枸橼酸咖啡因」），**含量 65 mg 一字未改**。
旧写法仍可检索：`cli.py "枸橼酸咖啡因"` → 提示「是 咖啡因 的常见误称」并落到 caffeine（`nickname.alias`）。
盐型名在页面上只出现在「Also called（别名）」行，成分名位零残留（抽检 acetaminophen 0 / caffeine 1 处仅别名 / lidocaine 1 处仅别名 / clindamycin 2 处其中 1 处是安全警示标题）。

**安全**：写前备份 `data/backups/drugs-20261114-104920.db`（452,550,656 B，sha256 `3F0AE738…`）；manifest 全量 old→new
`data/sources/inn_zh_salt_fix_manifest_20261115.json`；副本库 `--rollback` 演练（还原 339 行 + 删 339 条，二次回滚 exit 0）；写后 dry-run 幂等 0 行。
