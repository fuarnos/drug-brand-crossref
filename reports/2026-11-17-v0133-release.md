## 1. R1 国家/地区「本语言名称 · 简写」（site-ui / task-1）

- 新增 `_market_names()` / `_country_name()` / `_country_label()`：名称优先级 `UI_I18N home.<code>` → `data/markets.json name.<lang>` → 英文 → 简写，**不新造译名**；自动去掉与简写重复的尾部括号（「欧盟（EU）」→「欧盟」）。
- 渲染范围：结果行（`mktText` / `mktLabel`）、成分页市场块头、「也在」链接（前 3 + 「另 N 个市场」展开）、复方页、矩阵列头 `title` / `aria-label`、筛选 chip `title`。
- 长尾页（`drug/*.html` 只有一份英文产物）用 `data-mkc` / `data-mkc-name` 由 `i18n.js apply()` 按界面语言改写 → 切中文后块头「中国 · CN」、也在「美国 · US, 英国 · GB…」。
- 结果表市场列 **768px 起加宽到 32%**（`thead th:nth-child(4)`），标签按字符预算 27（CJK 记 2）挑：放得下 2 个就 2 个，否则 1 个 + 「+N」，完整列表进 `title`；实测 768/1024/1440 `clipped = 0`、390 `scrollWidth 375 < 390`。

## 3. R7 盐型词表补齐：品牌查询首行误挂徽章（site-ui / task-6）

- 根因：`site/build.py` 的 `SALT_WORDS` 85 词，`lib/search.py` 87 词，缺 **`hydrogen` / `oxalate`** → `Clopidogrel Hydrogen Sulfate` 只剥 `sulfate` 剩 `clopidogrel hydrogen`（基名不存在）→ 同一基名被当成两个成分 → 首行挂 `severe` + `combo`。
- 改法：Python 词表 85 → **87**（与 lib 逐字一致）；客户端 `G3_SALT_WORDS` 80 → **87**（元素名单独 `G3_ELEMENT_SET`），由 `deploy/ui_sort_smoke.py --strict-words` 常驻门禁；归并口径不变（仍要求「拆盐后基名在 substance 表里存在」，复方不走这条路径）。
- 效果（Lead 浏览器复验）：`plavix` 首行「氯吡格雷」**无任何徽章**，市场「澳大利亚 · AU, 加拿大 · CA +9」；`泰诺` 4 成分复方保留原样；`ui_sort_smoke` 规则 7/7、数据 8/8、`--strict-words` 0、exit 0（15.4s）。
