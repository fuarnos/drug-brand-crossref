## 2. 逐项：改了什么 / 字节 / 怎么验

### 2.1 项 1 · `core.json` 后台预取门控（`site/build.py` 的 `APP_JS`）

**改的函数**：`ensureCoreInBackground()`（原 `setTimeout(()=>loadIndex(true),0)`）重写为门控版，新增 `coreNetAllowsPrefetch()` / `coreLoadPending()` / `ensureIndexOnDemand()`；配套改 4 处调用点与 2 处 UI 逻辑：

| 位置 | 改动 |
|---|---|
| `ensureCoreInBackground()` | ① `navigator.connection.saveData` 或 `effectiveType ∈ {slow-2g,2g,3g}` → **完全不预取**；② 页面 `visibilityState==='hidden'` → 挂起，`visibilitychange` 回前台再试；③ 否则 `requestIdleCallback(fire, {timeout:8000})`（Safari 无该 API → 3 s `setTimeout` 兜底）。`LEGACY`（`?legacy=1`）早退不变。 |
| `startSearch()` 4 处调用 | `render()` 与 `ensureCoreInBackground()` 换序（先排预取、再渲染），否则首帧算不出「partial 且 core 在拉」这个状态，`#meta` 会漏掉「部分结果」提示。 |
| `render()` 的 partial 提示 | `if(partial)` → `if(partial && coreLoadPending())`：弱网/省流下不再谎称「正在加载完整索引」。 |
| `#country` 换国家 | `if(ctry.value) ensureIndexOnDemand();` —— 用户主动要「按国家看」= 明确需要聚合视图，按需 `loadIndex()`（HINT_LOADING + 失败重试照旧）。 |

**语义不变**：分片路径、identity 卡与命中表不动；`loadIndex(true)` 的失败降级（保留分片视图 + 警告）与 `loadIndex()` 的失败提示 + 重试按钮都不改。

**验证（真 Chrome + 桩 `navigator.connection`）**：`.tmp/perf-v0102/qa.json`

| 桩 | `core.json` 请求 | 备注 |
|---|---|---|
| `{saveData:true, effectiveType:'4g'}` | **0** | 分片照常 1 个请求、结果照出 |
| `{saveData:false, effectiveType:'3g'}` | **0** | 同上 |
| `{saveData:false, effectiveType:'4g'}` | 1（空闲后） | `?q=paracetamol` 后 idle 回调内拉 |
| 无 `connection` API（Safari 形态） | 1（3 s 兜底） | 与 v0.10.1 行为一致 |
| `{saveData:true}` + 切国家 US | **0 → 1** | 换国家后 `core.json` 才被拉，`meta` 保持「679 个名字命中」 |
| `?legacy=1&q=paracetamol` | 1（只 core、无分片） | 旧路径不变 |
| `{effectiveType:'4g'}` 搜索结果 | — | `#meta` 显示「部分结果 —— 正在加载完整索引…」按预期出现/消失 |

### 2.2 项 2 · i18n 按语言拆包 + 首页按需补载 + 回落

**改的函数 / 常量**

| 位置 | 改动 |
|---|---|
| 新增 `LANG_PICK_JS`（`LANG_META_JS` 之后，模块级常量） | 语言判定的**单一份源码**：`__dshLangHas` / `__dshCanonLang` / `__dshRelPath` / `__dshPickLang`（`?lang=` → 路径 → `localStorage` → `navigator.language` → `DEFAULT_LANG`）。boot.js 与 i18n.js 引用同一段文本，不会两处分叉。 |
| `_render_i18n_js(langs=None)` | 无参 = 四语全量 `assets/i18n.js`（404 页、老缓存页、回落用，保留）；`langs=['zh']` = 只含该语言的 `assets/i18n.<lang>.js`。单语包把「该语言缺的键」预置成 `window.I18N_FALLBACK`（zh-Hant 先回退简体再英文），本构建四语键集完全一致（见下），该表为空。 |
| 新增 `_write_i18n_assets()`（`main()` 内） | 一次写全量 + 4 个单语包，替换原先两处 `(OUT/'assets'/'i18n.js').write_text(...)`（初版 + 动态值回填后的第二版各调一次，行为不变）。 |
| i18n IIFE | `relPath/canon/pick` 改为调用 `LANG_PICK_JS`；`T()` 增加 `window.I18N_FALLBACK` 回落并给 `D.en` **判空**（单语包里没有 `D.en`，原写法会抛 TypeError）；`ROOT` 正则从 `/assets\/i18n\.js.*$/` 改成 `/assets\/i18n(?:\.[A-Za-z-]+)?\.js.*$/`（**必须改**：否则单语包的文件名会留在 ROOT 里，`langTarget()` 拼出的语言链接直接 404，等同 v0.9.7 那个坑）。 |
| 首页补载分支 | `__I18N_PARTIAL && !D[LANG]` 时只补 `assets/i18n.<LANG>.js?v=BUILD_V`，`onerror` 回落四语全量 `assets/i18n.js`。 |
| `boot.js` 生成 | 前面拼 `LANG_META_JS + LANG_PICK_JS`，算出 `LK=__dshPickLang(rootPath)`，`load` 后插 `assets/i18n.<LK>.js`；`onerror` 回落全量 `i18n.js`；随后照旧插 `bilingual.js`。 |
