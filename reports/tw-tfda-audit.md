## 4. 覆盖分析（入库关键）

### 4.1 成分（比预期好：英文可映射）

- 有效产品 23,083 张中 **22,716 行（98.4%）** 的 `主成分略述` 可拆出合规英文 token；共 **3,354 个不同 token**；多成分 6,434 行（27.9%）。
- Top token：ACETAMINOPHEN 1,076、CHLORPHENIRAMINE MALEATE 1,064、CAFFEINE ANHYDROUS 749、DL-METHYLEPHEDRINE HCL 641、SODIUM CHLORIDE 456、DEXTROMETHORPHAN HBR 430…
- **与站内现有 12,339 个英文成分名（`index.json` 的 `x`/`v` 词典）重合 86.3% 行**（19,597/22,716；token 级 31,696 次命中）。
- 未匹配 Top（需补盐型/别名映射）：`DL-METHYLEPHEDRINE HCL`、`GUAIACOL GLYCERYL ETHER`、`ETHENZAMIDE`、`POTASSIUM GUAIACOLSULFONATE`、`L-MENTHOL`、`ALUMINUM HYDROXIDE DRIED GEL`、`PANTOTHENATE CALCIUM`、`NOSCAPINE`、`ECONAZOLE NITRATE`、`GLYCYRRHIZA EXTRACT`…（多为复方感冒/止咳/外用老药 + 植物提取物）。
- 映射建议：`主成分略述` 优先（英文 INN-like），**不要**从中文品名反推；按 `;;` 拆分 → 去 `(EQ TO …)` / 剂型/含量括号 → 盐型后缀剥离（HYDROCHLORIDE/HBR/HCL/SODIUM/CITRATE/…）+ 站内别名表 → 剩余 13.7% 建一张「TW 成分别名词表」（人工 ~300–500 个 token）+ 植物药/疫苗单列。英文品名含成分名的仅 27.1%，故跨市场匹配应以成分 token 为键、品牌名只作展示。

### 4.2 规格（最大缺口：无结构化剂量）

- **数据集中没有 strength/含量字段**；`包裝` 也只有包装形态。
- 中文/英文品名里能粗抽「数字+单位（mg/g/ml/IU/%/毫克/公絲…）」的仅 **13,047/23,083 = 56.5%**；`主成分略述` 里带数字 0.8%。
- 品名规格串形态多样：`500毫克`、`10 mg/mL`、`200mg/5ml`、`500國際單位`、`１０％`（全角）、`0.1 g/0.2 g` 多剂量、复方「每錠含 A 5mg/B 10mg」（不在名里）→ **只能做「名称解析 + 置信度」**；疫苗/生物制剂还有「劑量以 mL/units 计」的问题。
- 影响：本站「同成分剂量对应」功能对 TW 只能覆盖约一半许可证，且需标注「规格由品名解析」；建议先上「名称/成分/剂型」检索层，规格列显示「未载/待解析」，避免误导。

### 4.3 品名 / 剂型 / 厂商

- 中文品名常含厂牌引号前缀与全角数字（需 NFKC + 去引号/厂牌归一）；英文品名常含剂型/剂量后缀（与中文名不一致，需分别存储）。
- 剂型 205 种（有效未过期），top25 覆盖 88.2%，其余长尾（药胶布、透析液、疫苗佐剂等）需枚举映射表；`原料藥` 的「（粉）」等剂型不属产品层，已排除。
- 外资制造 25.1%（DE 801/US 589/JP 536/IN 354/IT 352/FR 348/CH 338/IE 234/BE 201/ES 197/GB 188/DK 133…）→ 与 DE/US/JP/ES/GB/CA 等市场做同成分上市对应时，可先用「成分 token + 英文品名/厂商」交叉验证；同品牌不同市场需注意 TFDA 名可能是本地译名。

### 4.4 边界（中藥 / 动物药 / 历史数据）

- 数据集说明：中藥请另查 DOCMAP、动物用药/化粧品不在内；但实测**确有少量中藥/植物药**：`內衛成製字` 等 320 张成藥中可见 `PHELLODENDRON;;GLYCYRRHIZA`、`GLYCYRRHIZA EXTRACT` 等；另有 368 行成分含中藥材拉丁名（含 SILYMARIN/水飛薊提取物这类植物药，是否排除需人工定标）。`藥品類別` 里「限由中醫師處方使用」仅出现在**已注销**历史行（现行未过期 0 行）。
- 建议过滤：`註銷狀態` 非空 → 不进产品层（保留历史做状态）；`有效日期 < today` → 过期；`許可證種類` ∈ {製劑, 菌疫}；`主成分略述` 命中中藥材名单/成藥中的中藥成方 → 人工复核后排除（草案 356 张）；`原料藥/體外試劑/衛生材料/硬空膠囊` 排除。

## 5. 入库建议

### 5.1 口径与预估

1. 取现行（`註銷狀態` 空）**且** 未过期 **且** 种类为製劑/菌疫 → **21,988 行**；
2. 按整行/证号去重 → **18,554 个许可证**（1,980 个多行变体需合并为「同一产品多包装」）；
3. 排除中藥/植物药边界（草案 356 张，需人工复核）→ **≈18,198 张**；
4. 预估产出：**~18.2k 产品**、~18.3k 中文商品名 + ~18.1k 英文名、成分 token 3,354 类（86% 可直接映射现有成分，余 14% 建别名词表）、~205 剂型枚举、~2.6k 外资/进口产品（跨市场线索）。

### 5.2 字段映射草案（→ 本站 schema 方向）

| TFDA 字段 | 目标 | 处理 |
|---|---|---|
| 許可證字號 | `product.external_id`（source=`tw_tfda`） | 去重；多行变体用 `license_no + hash(包裝/劑型)` |
| 中文品名 | `product_name`（lang=zh-Hant, type=trade） | NFKC、去引号厂牌前缀（另存 manufacturer 关系）、保留原文 |
| 英文品名 | `product_name`（lang=en, type=trade） | 去剂型/剂量后缀前先保存原文；不强行当成分 |
| 主成分略述 | `product_component`（多条） | `;;` 拆分 + `(EQ TO …)` 清洗 + 盐型剥离 + 站内英文名匹配（86%）+ 别名词表补 14% |
| 劑型 | `dosage_form` | 205→~30 枚举映射；未知保留原文 + flag |
| （无字段）規格 | `variant.strength`（可空） | 仅品名解析（56.5%）且标 `source=name_parse, confidence=low/med`；复方多成分不拆剂量 |
| 申請商名稱 / 製造商名稱 | `mah` / `manufacturer` | 繁中公司名，去空白归一；制造国别存 `manufacture_country`（非市场国） |
| 製造廠國別 | 辅助 | 用于跨市场匹配与「产地」展示 |
| 藥品類別 | `regulatory_class` 标签 | 处方/指示/成藥/管制；只做事实标签 |
| 有效日期 / 註銷狀態 | `status`（active/discontinued）+ `valid_until` | 现行未过期=active；注销/过期=discontinued |
| 適應症 / 用法用量 | **不展示/不存正文** | 若需检索可只存关键词（不推荐）；保持本站「不给用药建议」边界 |
| 許可證字號旧号/通關編號 | 辅助追溯 | `舊證字號` 可做历史合并线索 |

### 5.3 分阶段与工作量

| 阶段 | 内容 | 预估 |
|---|---|---|
| P1（MVP 可检索） | `etl/ingest_tw_tfda.py`：读缓存 CSV → 过滤/去重 → 成分映射（86% 直配 + 盐型规则 + 别名词表草案）→ 剂型映射 → 写 `product/product_name/product_component/mah/source`（TW）→ 计数/抽查 | **2–3 人日** |

| P3（合规收尾） | About 三语署名段 + `docs/许可清单.md` 加 TFDA 行 + `run_all.py` 接入 + 回归测试（unittest/三语） + 发布前 check_data | **+1 人日** |

### 5.4 繁体名 → INN 映射难点

- **不要把中文品名当成分**：TFDA 中文名是商品名（且带厂牌前缀/全角剂量），通用名多在括号或英文名；正确路径是 **`主成分略述`（英文）→ 站内 INN/substance**。
- 盐型/复方/生物制剂命名差异：`DILTIAZEM HYDROCHLORIDE`、`AMLODIPINE BESYLATE` 等盐型需剥离；疫苗（`PNEUMOCOCCAL POLYSACCHARIDE SEROTYPE …`、`TETANUS TOXOID`）与生物制剂（`PEGYLATED`、`FUSION PROTEIN`）在现有库中可能无对应 substance → 保留原始 token + `unmapped` 标记，不硬造成分。
- 中文译名（如「貝瑞酶」「立美西膚」）只能靠英文/成分匹配；同成分多品牌在 TW 内也常见（8,298 重名），符合本站「名称不是主键」原则。

| 风险 | 说明 | 缓解 |

| 许可署名义务 | OGDL v1 要求「顯名聲明」，未履行视为未授权 | About 加固定段落（数据集名+机关+年份+版本+https://data.gov.tw/license），并保留 `data_as_of` |

| 数据集可能扩展/改版 | 字段/许可变化需重新审计 | fetch 脚本记录 metadata；每轮抓取先看 `modifiedDate`/字段数 |
