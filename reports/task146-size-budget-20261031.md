# task-146 dist 体积预算（2026-10-31 实测）

> 只读实测 `site/dist`（v0.9.4 产物，121,290 文件 / 941,874,387 B）。结论用于决定 task-145 的落地形态。
> **900 MiB = 943,718,400 B**；当前 **941,874,387 B** → **余量 1,844,013 B = 1.76 MiB**。

## 0. 结论

- **ATC4 事实表走客户端 JSON**：`data/idx/atc4-forms.json` **1.21 MB raw / 163 KB gzip**（28,378 行），能塞进 1.76 MiB 余量，但只剩 ~0.6 MiB 缓冲。
- **不要做 798 页静态明细表**：28,378 行 × ~130 B ≈ **3.7 MB**，直接超限。
- 要长久的余量，唯一划算的杠杆是 **name 页瘦身**（77,058 页占 **359.4 MiB / 50.7%**，均 4.8 KB）——模板每页省 2 KB 就是 **150 MB**。
- 顺带发现：`form_base` 有 **876 个取值**（AU 导出夹带自由文本，如 `afamelanotide 16mg implant`、`0-unassigned`），前 30 个覆盖 99.41% → 已加进设备归一化清单（task-148）。

## 2. task-145 的三种形态

| 形态 | 增量 | 可行性 |
|---|---|---|
| **A 客户端 JSON**（推荐） | **+1.21 MB raw / 163 KB gzip** | ✅ 在余量内；ATC4 页加「按剂型看明细」按钮，按需 fetch |
| B 每页静态一行摘要（成分 × 剂型数） | +0.6–0.9 MB | ⚠️ 勉强，且信息量有限 |

**定案：A + 在 ATC4 页加一段「同类 ≠ 可互换」四语 notice（静态）。** C 若将来要做，先做 §3 的腾空间。

## 3. 腾空间候选（按性价比排序）

| 措施 | 可省 | 风险 / 代价 |
|---|---|---|
| **name 页模板瘦身**（77k 页均 4.8 KB；页头/导航/页脚复用约 2.2–2.8 KB） | **120–150 MB** | 需改 `build.py` 模板；不影响 LCP 目标页（前 4 页另测） |
| core.json 瘦身（41.4 MB raw → 目标 ≤30 MB） | **11 MB** | 需改列式编码/字典；客户端 `decodeCore` 同步 |
| 8,455 combo stub 压缩到 ~400 B/个 | **5 MB** | 需保证旧 URL 200 + noindex 语义不变 |
| 单包装 name 页从 44,040 减到 CN/TW 优先 | 100+ MB | 影响 UX（可点性），不建议先做 |
| 删 `data/artg.json` 快照（4.6 MB） | 4.6 MB | 数据产品/溯源需要，先别动 |
