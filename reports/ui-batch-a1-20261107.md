## 6. 已知缺口 / 未做

1. **同成分区块改成列表**：原来两张宽表（成分/剂量/品牌/厂家，最多 80 行/张）信息更全但 DOM 巨大；现在每段前 8 条 + 「另有 N 个」，要全量请看成分页。若后续想要回来，需先给「同成分」区块单独算 DOM 预算。

3. **品牌列语义未动**：索引里 `t!==1` 的条目仍显示「无商品名 + 命中名」，这是 v0.9.0 task-19 的既有规则，不在本批范围。
4. **ATC/大类结果**仍用原来的分组表（`RES_MODE='grouped'`），只改了普通名称查询；两者共用 `paintResultsOnly`/分页状态，已回归验证（`?q=C07AB` 未变）。
