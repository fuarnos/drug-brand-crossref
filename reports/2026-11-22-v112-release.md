## 2. 护栏调整（Lead 决定，release 执行）

```python
# deploy/verify_live.py
CORE_GZ_RANGE  = (2_500_000, 16_000_000)   # 原 (2_500_000, 12_000_000)
CORE_RAW_RANGE = (11_000_000, 80_000_000)  # 原 (11_000_000, 50_000_000)
```

- **理由**：KR +97,356 产品让完整索引从 44.76 MB raw / 10.10 MB gzip 自然增长到 **67.96 MB raw / 13.32 MB gzip**——属内容增长、非回归（原注释本身也这么写）。不改就会在 `verify_live` 上误判失败。
- **范围**：只改数值 + 注释；`INDEX_*`（legacy index）不动——legacy `index.json` 已关，`verify_live` 里「404 属预期」。
- **已入库**：`ebbd82808a2`（Lead commit）；AGENTS §6 的护栏口径同步改为「gzip 2.5–16 MB / raw 11–80 MB」，并写明**下一次接近上限前必须先做「索引按文字系统分片」，而不是继续调高**。
- 余量：当前 13.32/16 MB（83%）、67.96/80 MB（85%）——**下一版再加一个大市场就会顶到上限**，分片需要提前排期。
