## 4. 已知缺口

### 4.1 许可（阻塞项）

- GIP 无许可声明；`data.overheid.nl` 该数据集 `dct:license = licentieonbekend`，目录口径页把
  「许可未知」定义为**无再使用许可**。详见 `reports/2026-11-11-nl-license-assessment.md`、`docs/许可清单.md` §2.10。
- 因此 `etl/markets/nl.py` **不提供 `--apply` / `--rollback`**（文件头、`--help`、`--self-check` 三处都断言了这一点）。
  许可落地后，按 `etl/ingest_eu.py` 的三段式（`--apply` / `--manifest` / `--rollback`）补写库与撤销清单即可。

### 4.2 schema 前置（入库前必须先做）

- `product.country` 的 CHECK 枚举目前没有 `'NL'`（US/GB/CN/ES/MX/AU/CA/TW/HK/SG），要做
  `db/init_db.py` 幂等迁移 + `markets.json` 注册，才能谈写入。
- `TOEDIENINGSWEG` 是多值串（119 种写法，含 `A + B` 组合），`product.route` 是单值列 → 需要定口径
  （取主途径 or 拆多行），本期没做。
- `AFLEVERSTATUS` 的组合串用 `$SEMICOLON$` 分隔（如 `Uitsluitend apotheek$SEMICOLON$ …`），
  映射 `category`（Rx/OTC）前要先拆串。
- 3,831 行 `EU/…` 集中审批产品与 `region='EU'` 层重叠，需要「按 EU 号去重、NL 层只留成员国数据」的规则。

### 4.3 成分映射率（78.6% → 想再提高要靠数据，不靠代码）

未映射 1,093 种，按类别：

1. **多段盐/酯连写**：`NATRIUMWATERSTOFCARBONAAT`、`FENTANYLDIWATERSTOFCITRAAT`、
   `RIVASTIGMINEWATERSTOFTARTRAAT`、`DABIGATRANETEXILAATMESILAAT` —— 需要「荷兰语盐名词表 + 多段拼接切分」。
2. **荷兰语基名拼写差**：`TRYPTOFAAN`、`BROOMHEXINE`、`COFFEINE`、`SOJAOLIE`、`*ZUUR`（酸）——
   需要 NL→INN 同义词表（`docs/` 里没有，属新增人工数据，先不造）。
3. **顺势疗法 / 植物名**：`RHUS TOXICODENDRON`、`LYCOPODIUM CLAVATUM`、`NUX VOMICA`、`HEPAR SULPHUR` ——
   库里没有这些 substance，属「本就不该挂」，应在入库时归 `unmapped` 并标顺势疗法。
4. **只有离子/盐片段**：`WATERSTOFCARBONAAT (HCO3-)` —— 无基名，无法挂 substance。

### 4.4 `POTENTIE` 不是规格列

453 行非空、0 行能解析成数值（全是 DH/CH/K/LM 稀释度）。任何「NL 有规格列」的说法都不成立，
规格只能从 `PRODUCTNAAM` 抽。另：`PRODUCTNAAM` 里有 2,307 个多规格（复方 `200 mg/50 mg/200 mg`、
或名称里写了两遍剂量），本期不猜「哪段数值属于哪个成分」，一律留空。

### 4.5 `name_key` 会被荷兰语剂型词污染

`normalize()` 的剂型词表是英文/西语/中文（`solution`/`injection`/`tablet`…），不认荷兰语
`oplossing`/`injectie`/`tabletten`/`zalf`。所以 `Digoxine Eureco-Pharma, oplossing voor injectie 0,5 mg/2 ml`
的 key 会留下 `oplossing injectie` 之类的尾巴 → `name_key` 新建数（10,652）偏大，且同一品牌会被拆成多个 key。
修法：给 `etl/normalize_name.py` 的 `_FORM_TOKENS` 补荷兰语词（会动到全库检索键，需单独立项验证，
本期**不改**别的文件）。

### 4.6 页面口径（写页面时必须照做）

- **荷兰语原文**：商品名、剂型、给药途径全部按 `PRODUCTNAAM` / `FARMACEUTISCHEVORM` /
  `TOEDIENINGSWEG` 原样显示，不翻译、不臆造中文剂型名。
- **数据滞后两周**：数据方每周更新但发布滞后两周（本快照 `Last-Modified: 2026-11-04`，抓取日 11-10）。
- **`SOORT=RVH` 是「handelsvergunning」，不是集中审批**；集中审批那批 `SOORT` 为空、注册号 `EU/…`。
- 真正能给的只有「身份对应」：产品名、成分、剂型、规格、ATC、持有者、处方/非处方状态。
  **不给用药建议、不做剂量换算、不判断互换。**
