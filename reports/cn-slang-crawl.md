# 中文互联网药品俗名抓取（阶段 A）报告

> 日期：2026-10-27 ｜ 任务：docs/谷段需求队列.md「俗名/街头叫法抓取」阶段 A（中文互联网）
> 产出：`etl/fetch_cn_slang.py` + `data/raw/cn_slang/`（raw_terms.jsonl / state.json / events.jsonl / raw/ 缓存）
> 本脚本只抓「短事实」，抽取与合法性过滤由 `etl/extract_cn_slang.py`（另一管线）读 raw_terms 完成。

## 1. 结论

- **raw_terms.jsonl 共 772 行短事实**，覆盖 78 个检索词（72 个种子 + 维基部分条目标题差异）；来自 4 个来源：百度搜索、必应搜索、头条搜索、中文维基。
- 已用请求 162 次，全部按 3–5 秒随机抖动限速串行；缓存原始页 + 断点续跑状态。
- **封禁/验证码来源 3 个**（已立即停用并记录，降到搜索兜底）：搜狗搜索、百度百科、知乎。
- 命中「毒品/娱乐性用药」而丢弃的行：**2** 条（关键词表过滤，见 §6）。
- 中文维基、必应、头条搜索、百度（离线重解析）可用；搜狗/百度百科/知乎在当前无登录直连下被验证码/403 拦截，小红书/微博/贴吧返回 JS 或登录壳（详见 §3–§4）。**抓不到的来源如实记为失败，不用任何绕过手段。**

## 2. 抓取纪律（按需求队列与任务约束执行）

- 限速：请求之间 `random.uniform(3.0, 5.0)` 秒（`--min-delay/--max-delay` 可调），全程串行、无并发。
- 不登录、不绕验证码、不破解签名接口；请求带清晰 UA（含项目地址说明）与 `Accept-Language: zh-CN`。
- 遇 403/429/验证码/安全验证页：该来源立即停用，写 `events.jsonl`，降级到其他来源；所有来源都被封才整体停止。
- 只存短事实：`term / platform / url / title(≤120) / snippet(≤220) / fetched_at / lang`；**不存用户名、头像、主页、正文大段**；原始页只做本地缓存（data/raw 不进仓库）。
- 毒品/娱乐性用药内容：标题/摘要命中毒品黑话关键词表 → 直接丢弃、只计数不落盘。
- 断点续跑：`state.json` 记录已完成查询（`done`）与每来源统计；重跑默认跳过已完成项。

实现方式：

- **中文维基**：`zh.wikipedia.org/w/api.php`，每批 20 个条目取 `extracts`（引言），正则抽「又称/俗称/别名/又名/旧称/曾用名/商品名/英文名」句；1 个请求覆盖 20 个种子，最省。
- **必应（兜底）**：`www.bing.com/search`，先访问首页取 cookie 再查；反爬降级时返回的无关结果（购物清单/字典/翻译）用相关度规则丢弃并计入 `irrelevant`。
- **头条搜索（额外兜底）**：`so.toutiao.com/search`，解析内嵌 JSON 的 `emphasized.title/summary`；实测相关性最好、无封禁。
- **百度**：首轮返回真实结果页（~0.9 MB）但 2026 版页面把水合 JSON 混进摘要，通用解析器抽不出干净短句 → 脚本 `--reparse` 离线重解析已缓存页（剥 JSON 片段 + 药品词句校验），补出 22 条事实（3 个种子）。
- **搜狗 / 百度百科**：返回「验证码/安全验证」页（HTTP 200 / 403），按纪律立即停用并写事件。
- **小红书 / 知乎 / 微博 / 贴吧（直连尝试）**：按用户授权试了公开页；知乎/贴吧 403，微博返回登录/访客壳，小红书返回 JS 空壳（无服务端结果）。已各停用并记录，未做任何登录/签名绕过。

## 4. 输出格式（extractor 的输入契约）

`data/raw/cn_slang/raw_terms.jsonl`：UTF-8，每行一个 JSON 对象，字段固定为

| 字段 | 含义 | 约束 |
|---|---|---|
| `term` | 本次检索的药品名/别名种子（如「布洛芬」「必理痛」） | ≤40 字 |
| `platform` | 来源标识：`wiki` / `bing` / `toutiao` / … | enum |
| `url` | 原文 URL（可点回原页核实） | http(s) |
| `title` | 页面/结果标题 | ≤120 字 |
| `snippet` | 含「叫法」证据的短摘要（≤220 字，不转载正文） | ≤220 字 |
| `fetched_at` | 抓取时间（ISO8601，带时区） | — |
| `lang` | 语言标记（本管线恒为 `zh`） | `zh` |

## 7. 缓存、断点续跑与可复现

- 目录：`data/raw/cn_slang/`（gitignore，不进仓库）：
  - `raw_terms.jsonl` 统一输出（extractor 读这个）
  - `state.json` 断点状态：`done` 查询列表 / 每来源统计 / `banned` 封禁来源 / 丢弃计数
  - `events.jsonl` 事件流：blocked / no_result / dropped_drug / error（审计用）
  - `raw/<platform>/<sha1>.html` 原始页缓存（只保留短事实抓取所需页面）
- 本轮完成查询 161 个；重复执行会自动跳过已完成项（断点续跑）。
- 离线重解析：`python etl/fetch_cn_slang.py --reparse`（只读缓存、不联网；本轮借此补出百度 22 条）。
- 复现：`python etl/fetch_cn_slang.py`（先 `--dry-run` 看计划，`--status` 看进度，`--reset-state` 重头抓；`--max-requests/--max-seeds/--only` 控制规模）。

## 8. 限制与下一步

1. **平台直连几乎全封**：小红书需登录+签名、知乎/贴吧 403、微博要访客 cookie、搜狗/百度百科要验证码；百度可用但需离线重解析。本管线按纪律只记录、不绕过。下一轮可考虑：① 官方开放接口/合作渠道；② 用户提供的浏览器会话导出（cookie 授权）后再跑（需人授权一次）；③ 继续以中文维基 + 头条 + 必应摘要为主，扩大种子与模板。
2. **必应反爬降级**：部分查询返回「购物清单/字典」类无关页（已用相关度规则丢弃并计数）；必要时换 `cn.bing.com` 或降低频率重试（脚本已含 cookie 预热 + 3–5s 限速）。
3. **本脚本不做抽取/定案**：raw_terms 只是「短事实原料」，候选词、繁简归一、与本地成分/商品名匹配、毒品过滤二次确认都由 extractor 完成；最终入库口径仍按需求队列（只进 `drug_term`、`nickname` 新增=0）。
4. **许可/ToS**：用户已明确授权尝试平台抓取并承担 ToS 风险；站外再发布只使用叫法事实 + 链接，不整段转载；平台侧若有异议可按 URL 下架对应事实（每行都带 url）。
