# 手机通道：手机看进度 / 发指令

人不在电脑前（手机、4G）时，用这个看项目进度、给 agent 留一句话下达下一步。
设计细节见 [手机通道-设计.md](手机通道-设计.md)。

## 一分钟上手

```powershell
$py = 'C:\Users\asus\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe'
& $py mobile/server.py                 # 或双击「手机看板.cmd」
```

终端会打印：

```
token  ：新建 / 沿用 .tmp\mobile\token.txt
本机   ：http://127.0.0.1:8787/?k=<token>
内网   ：http://192.168.10.115:8787/?k=<token>     ← 手机同 Wi-Fi 开这个
```

手机浏览器打开「内网」那一行，**存成书签**。之后每次电脑开着服务、手机在同一 Wi-Fi，点书签就能看。

要 4G / 外网也能看：

```powershell
& $py mobile/server.py --tunnel        # 或双击「手机看板-外网.cmd」
```

首次会自动下载 `tools/cloudflared/cloudflared.exe`（约 55 MB，只需一次），然后打印一个
`https://xxx-yyy.trycloudflare.com/?k=<token>`，手机用这个地址即可。
**快速隧道的域名每次重启都会变**；进程常驻期间稳定。要固定地址见下面「想要固定地址」。

## 手机上能做什么

- **看进度**：产品 / 成分 / 名字键 / 碰撞分级、各国条数、站点构建时间与文件数 / 索引体积、
  仓库分支与 HEAD / 未提交文件数、最近 5 份 `reports/`、待办队列。
- **发指令**：底部输入框写一句话 → 发送 → 进队列（`pending`）。**不需要 agent 此刻在线**；
  agent 下次开工先读队列、执行、在页面上回帖（`done` / `blocked`），你手机上刷新就能看到。
- 队列按时间正序显示，最新在最下面；每条带状态徽章和历次回帖。

## agent 侧怎么读队列

```powershell
& $py mobile/inbox.py pending                 # 开工先跑这个
& $py mobile/inbox.py list --all --limit 20   # 连已完成的
& $py mobile/inbox.py done <cmd_id> "已重建站，见 reports/xxx.md"
& $py mobile/inbox.py blocked <cmd_id> "缺 MX 许可结论，要人定"
```

队列文件 `inbox/commands.jsonl`（指令）与 `inbox/replies.jsonl`（回帖）都是 **append-only**，
进 git，跨会话可追溯；状态由最后一条回帖推导，不手工改历史行。规则也写进了
[AGENTS.md](../AGENTS.md) §7「手机指令队列」。

## 三种访问方式

| 方式 | 地址形态 | 需要 | 稳定性 |
|---|---|---|---|
| 局域网 | `http://192.168.x.x:8787/?k=…` | 同一 Wi-Fi、电脑开机、防火墙放行 | 内网 IP 偶尔会变，重开服务看新地址 |
| cloudflared 快速隧道 | `https://随机词.trycloudflare.com/?k=…` | 能连外网；exe 自动下载 | 每次启动换域名，进程活着期间稳定 |
| ssh 反向隧道（备选） | `ssh -R 80:localhost:8787 nokey@localhost.run` 给的地址 | 本机 OpenSSH（已装） | 免费服务可能限流，仅应急 |

想要固定地址：Cloudflare 命名隧道（需账号 + `cloudflared tunnel login`）或 Tailscale
（手机和电脑装同一账号，直接用 `http://100.x.y.z:8787`）。两者都要装东西/登录，按需再说。

## 安全边界

- **必须带 token**（`?k=` 或首次访问后种下的 cookie），没 token 一律 401，不泄露任何内容。
- token 自动生成后存在 `.tmp/mobile/token.txt`（`.tmp/` 已 gitignore，不进仓库）；也可用
  `--token` 或环境变量 `MOBILE_TOKEN` 指定。
- 同 IP 每分钟最多 20 次提交，单条正文上限 2000 字，超出 429 / 400。
- 隧道地址是公网可解析的：**别把带 `?k=` 的完整链接发到公开群**；token 泄露就删
  `.tmp/mobile/token.txt` 重启服务换一个新的。
- 页面只能读 `data/drugs.db`（`mode=ro`）和文本文件，**不能执行任何命令**；
  手机发来的指令只是文本，agent 执行与否由 agent 判断——涉及删数据、发布上线、花钱、
  改公开口径的，仍然先问你，不会照着队列直接干。

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机打不开内网地址 | 电脑和手机是否同一 Wi-Fi；Windows 防火墙首次会弹窗，给 Python 放行「专用网络」；确认终端打印的是 `0.0.0.0` 监听 |
| 端口被占用 | `--port 8788` 换一个 |
| 隧道没起来 | 看终端里 cloudflared 的输出；公司/校园网可能封端口。可改 `--protocol http2`（默认已是）或走局域网 |
| cloudflared 下载失败 | 手动下载 <https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe> 放到 `tools/cloudflared/cloudflared.exe` |
| 手机页面数字不动 | 页面每 20 秒拉一次 `/api/state`，但**进度数字不是每次都重算**：只在 `data/drugs.db` 或 `site/dist/index.html` 变了、或你点「刷新」（`?fresh=1`）时后台重算。点一下刷新按钮，约 12 秒后页面自己更新 |
| 电脑睡眠 / 关机 | 服务就没了——这不是云端服务，电脑得开着 |
| 隧道域名变了 | 快速隧道本来就不固定；见「想要固定地址」 |

## 已经验过的（2026-10-26）

- `& $py -m unittest tests.test_mobile_inbox -v` → **29 个测试全过**（队列、状态推导、并发进程/线程追加、坏行、CLI、端点 401/302/201/429）。
- 端到端（临时 inbox，不碰真实队列）：`/healthz` 200、无 token 401、`?k=` 302 + cookie、
  `/api/state` 连续 5 次 **2 ms**（快照缓存生效）、POST 201 → 队列 pending → CLI 读到 → CLI 回帖后状态变 done、
  空文本 / 超 2000 字 400、未知路径 404、错误 token 401、25 次 POST 出现 429。
- 公网隧道实连：`cloudflared 2026.10.4` 起的 `https://*.trycloudflare.com` 上，
  `/healthz` 200、`?k=` 302 + cookie、`/api/state` 200 且带真实数据（`db.total=409,485`、`v0.4.0`）。
- 页面静态检查：零外链资源、viewport 正确、输入框 16px、按钮 ≥44px、无 >320px 固定宽度、长文本有换行规则。


## 文件在哪

```
mobile/server.py     手机看板服务（页面 + /api/state + /api/command）
mobile/page.py       手机页面（内联 HTML/CSS/JS，无外链）
mobile/queue.py      队列库（append-only JSONL + 跨进程锁）
mobile/inbox.py      agent 侧 CLI
mobile/tunnel.py     cloudflared 快速隧道
手机看板.cmd          双击启动（局域网）
手机看板-外网.cmd     双击启动（带 cloudflared 隧道，4G 可用）
inbox/               指令与回帖数据（进 git）
docs/手机通道-设计.md  契约与接口
```

## 已知缺口

- **看不到「构建跑到哪一步」**：`site/build.py` 不写日志文件，页面只能显示 `site/dist` 的时间、
  文件数，以及在 90 秒内改过时标「可能正在构建」。
- 快速隧道域名不固定；固定地址要命名隧道或 Tailscale。
- 没有推送通知：指令执行完不会主动响铃，得自己刷新（要推送得另做 PWA / 邮件 / 微信，按需再议）。
- 没有多用户和权限分级：拿到同一个 token 的人看到的、能发的都一样。
