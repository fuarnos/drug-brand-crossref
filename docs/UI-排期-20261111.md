## 三、每版验收口径（缺一条不算完）

1. `deploy/i18n_check.py` **FAIL 0**（四语键集一致；新键必须进 `data/i18n_zh_hant.json`，只许经生成器重生成）。
2. 全量构建到 `== done ==`；页数 / 总字节 / `core.json` raw / sitemap URL 数与上一版对比（退化超 5% 要写理由）。
3. `deploy/first_screen_check.py` 改前 / 改后各一次，至少覆盖 home / results / drug / atc × 390x844 / 1440x900；**正文 ≥16px、辅助 ≥13px、任何可见文字 <12px 即违规**。
4. 三语各抽 3 条检索（基线：泰诺 3 / Paracetamol 500mg 679 / 两只青蛙 1043），语言间结果一致。
5. `impeccable detect` 复扫关键页（`atc/A` 的 cramped-padding、`drug/*` 的 skipped-heading 应下降）。
6. 链接 / 404 / sitemap 抽检；构建确定性（同输入两次逐字节一致）。
7. 报告落 `reports/`，数字写清命令与改前改后。

## 四、两条数据依赖项的边界

- **条目 12（商品名页加厚）**：模板是主要工作量，但「状态 / 登记号 / 来源」取自 `product.status`、各市场注册号与 `source` 字段 —— **只渲染已存在的字段，不新造数据、不改口径**。
- **条目 27（名称表达统一）**：规则是 UI，能不能给中文名取决于 `name_lang`。**没可靠中文名就不硬翻**，宁可用原文 + 语言标记。
- 两条都**不触碰三条底线**：查询仍返回候选集、碰撞仍自动推导、不给用药建议与剂量换算。
