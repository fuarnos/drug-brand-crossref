싫으면 안 올려도 되고 ㅎㅎ). 안 되면 그냥 편하게 말해줘! 고마워 :)

## §2 정식 설명 (메일용)

```text
안녕하세요,

먼저 제가 무엇을 하고 있는지 간단히 설명드리겠습니다.
저는 여러 나라의 약 이름을 서로 대조해 주는 비영리 참고 사이트를 만들고 있습니다.
약 이름(브랜드명·일반명·포장에 적힌 문구)을 입력하면 그 제품이 어느 나라의 무엇인지,
성분과 함량은 무엇인지, 다른 나라에서는 어떤 이름으로 유통되는지를 보여줍니다.
약을 추천하거나 용량을 계산하지는 않고, '같은 제품인지 아닌지'와
'서로 바꿔 먹으면 안 됩니다' 같은 주의만 표시합니다.

현재 중국·미국·영국·캐나다·호주·일본·프랑스·스페인·멕시코·대만·홍콩·싱가포르·
체코·라트비아·EU 등 15개 시장이 들어가 있고, 한국 자료만 없습니다.
한국은 꼭 포함하고 싶어서 식품의약품안전처의 공공데이터
「의약품 제품 허가정보」를 사용하려고 합니다.

문제는 이 데이터가 공개 데이터임에도 불구하고, 공공데이터포털(data.go.kr)과
식의약 데이터 포털(data.mfds.go.kr) 모두 회원가입 및 신청 단계에서
휴대폰 본인인증(한국 통신사 번호)을 요구한다는 점입니다.
제가 해외에 있어서 이 절차를 혼자 진행할 수 없습니다.

그래서 부탁드리고 싶은 것은 아래 두 가지 중 하나입니다.

[방법 1] API 인증키 전달
  1) https://www.data.go.kr 로그인 (휴대폰 본인인증)
  2) 아래 데이터셋 접속
     https://www.data.go.kr/data/15095677/openapi.do
  3) 「활용신청」 클릭, 활용 목적 예시:
     "비영리 참고 사이트에서 의약품 이름 대조 데이터로 활용 (개인 학습용)"
  4) 승인 후 마이페이지 → 활용신청 결과 → 「인증키」에서
     Encoding 인증키를 복사해 전달

[방법 2] CSV 파일 전달
  1) https://data.mfds.go.kr 로그인 (휴대폰 본인인증)
  2) 상단 「파일데이터」 → 「연도별 공공데이터 파일」
  3) 「의약품 제품 허가정보」(최신 연도) CSV 다운로드 후 전달

사용 범위와 관련하여 아래를 약속드립니다.
- 이 데이터는 「이용허락 제한 없음」 공공데이터이며, 사이트에는 출처(식약처)와
  데이터 기준일을 반드시 표기합니다.
- 상업적으로 판매하지 않으며, 개인정보나 결제 정보는 전혀 필요로 하지 않습니다.
- 인증키는 제 작업 환경의 비공개 설정 파일에만 보관하고, 공개 저장소나
  웹사이트에는 절대 포함하지 않습니다.
- 필요하시면 언제든지 마이페이지에서 활용신청을 취소(중단)하실 수 있습니다.
- 호출량은 하루 수십 회 수준입니다(전체 목록을 페이지로 나눠 받는 정도).

시간 되실 때 가능한 방법 하나만 알려주시면, 제가 나머지 절차를 정리해서
다시 보내드리겠습니다. 어려우시면 편하게 말씀해 주세요. 늘 감사합니다.
```

## §3 상대가 보내주면 되는 것（你收到后给我即可）

- **API 路线**：`Encoding 인증키` 一串（约 40–80 字符，含 `%2B`/`%3D` 等编码字符也可以，原样发我）
- **CSV 路线**：`의약품 제품 허가정보` 的 CSV 文件（哪个年度都行，越多越好），或网盘链接
- 顺带告知：**数据截止日期**（文件名或页面上通常有）

## §4 你要替对方把住的三条（不用发给对方）

1. **不要让对方给你账号密码**——只要文件或 key。
2. **key 只进 `.env`**：不进仓库、不进 `site/dist`、不贴进对话以外的任何文档。
3. 对方若不想实名，就停在 **K2 链接层**（覆盖页/About 加 MFDS 官方查询入口 + 署名），不勉强。
