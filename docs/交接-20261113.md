## 4.1 ⚠️ git push 凭证/TLS 注意（本机新坑，下次直接用）

本机 `git push` 用默认 schannel 会报 `SEC_E_NO_CREDENTIALS (0x8009030e)`（沙箱拿不到 Windows 凭证库）；`http.sslBackend=openssl` 又会因仓库路径含中文导致 CA bundle 读取失败。**可用组合**（本次已跑通，push main / tag 均 exit 0）：

1. 把 `tools/git/ucrt64/etc/ssl/certs/ca-bundle.crt` 复制到 ASCII 路径（如 `$env:TEMP\ca-bundle-drug.crt`）；
2. 从 `.env` 的 `GITHUB_TOKEN` 导出环境变量（有效，API `/user` = `fuarnos`），写一个 `GIT_ASKPASS` 脚本 `@echo %GITHUB_TOKEN%`，设 `GIT_TERMINAL_PROMPT=0`；
3. push 用带用户名的 URL：`git -c http.sslBackend=openssl -c http.sslCAInfo=<ascii-ca> -c credential.helper= push https://fuarnos@github.com/fuarnos/drug-brand-crossref.git main`（tag 同理）。
4. 不要把 token 写进 command line / 日志；`.tmp/askpass.cmd` 用完可删。
