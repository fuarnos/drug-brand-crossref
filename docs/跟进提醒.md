## 到期判定（每日开工核对）

- 每次谷段**开工**读本页：当天日期 ≥ 提醒日期且状态仍为「等待回复」→ 在开工汇报里标红一次，并写进当天 `reports/` 早报；同一提醒日期只在当天提一次，不重复骚扰。
- 未到期（当天 < 提醒日期）→ 不动作，只在有实质变化时更新本页。
- 同一申请多个提醒日期：后一个日期覆盖前一个的跟进动作（11-12 查进展，11-26 查法定答复）。
- 答复到达 → 更新本表状态为「已答复（日期）」，并转到 `docs/谷段需求队列.md` 的台账与后续任务；**已答复的申请不再保留提醒节点**（TGA 11-24 已关闭，只留 11-03/11-10 核对条款与补问）。
