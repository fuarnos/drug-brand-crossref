## 2. 本日必做（按顺序，做完勾掉队列）

1. `db/check_data.py` 留一次基线（写进交接）。
2. 从队列取 **P1 待办**，一次只做 1–2 项；重活安排在谷段（北京 00:30–08:30）。
3. 改完按 `AGENTS.md` §5 验收门槛跑对应测试；发布按 §6 流程（唯一入口 `deploy/publish.ps1`）。
4. 收尾：更新 `docs/谷段需求队列.md`「已完成」+ 写 `docs/交接-YYYYMMDD.md` + 更新本卡 §1 状态表。

## 3. 红线速查（不许越）

- 商品名不是主键，查询永远返回候选集。
- 只做身份对应 + 「不可互换」警示：**不给用药建议、不做剂量换算、不判断两药能否互换**（理由见 `docs/为什么不做替代推荐.md`）。
- 碰撞由 `collision` 视图自动推导，不手工标注。
- 不做 login；不付费买数据；不绕 WAF；不手工推 `gh-pages`；不提交 `data/*.db`、`site/dist/`、`.tmp/`、`.env`、`tools/`。
- 涉及花钱/删数据/改公开口径：写进报告等你看到，不擅自执行。

## 4. 省 token 守则（余额有限）

- 读文件用 offset/limit，别整篇拉；日志只 tail 关键行。
- 一次构建串多个任务，不要每个小改动都 `build.py`（全量 ~20 分钟）。
- `site/build.py` 与 `publish.ps1` 串行，不并行。
- 报告写「结论 + 命令 + 数字」，不贴长日志。
- 发布前只跑 `ci_checks.py --fast`（18s）；全量 CI（~12 分钟）放在正式发版前一次。
