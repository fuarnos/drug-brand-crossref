# 每日开工卡（新对话从这里开始）

> 用户 2026-10-30 交棒：项目由 agent 自主推进，人只每天开一个新对话。**新对话第一条消息只需「开工」**，其余照本卡。
> 维护：每天收尾时更新本文（`docs/交接-YYYYMMDD.md` 写当天细节，本文只留最新状态）。
>
> **本卡只适用于「谷段交付会话」**（判定见 `AGENTS.md` §12「会话两型」）：首条消息首行带 `【谷段交付会话】` 标签、或人明确说「开工 / 现在做 / 紧急」的会话，才按本卡开工。**其余会话——尤其是人手动新建的对话——一律是「对接会话」**：先回答 → 登记 `docs/谷段需求队列.md` → 拆解派单；只读查证可以，**不 build / 不发布 / 不写库 / 不改实现 / 不开长任务**。**人类消息优先：回话 ≠ 开工，答完即停**（用户消息 → 回答 + 登记 → 结束本轮，不继续手上的活；主对话没有用户消息时保持空闲，「队列里还有待办」不算继续干活的理由）。

**自动开工（2026-11-10 起）**：每天 **北京时间 00:30（谷段开始）** 由 scheduled task `schedule-1ef25825-b30a-4c13-8280-2d773b37bd07`（`target=new`）自动开新会话，prompt 首行带 `【谷段交付会话】` 标签（即「开工」指令），无需人手动开。**仍禁止**在旧会话里建长期 cron/at（会话级 schedule 不继承，旧会话会在无人值守时烧余额）；只保留这一个每日任务。

**工作模式（2026-11-20 用户重设，取代 2026-11-11 的 8 工位）**：你是 **Lead**，按 `docs/工作组与流程.md` 运转。

- 核心编制：**1 个 Lead + 4 个工位**——`data-scout`（数据扩展：找源 / 许可 / 评估 / 申请）、`backend`（后端：`etl/`、`db/`、`lib/`，唯一 DB 写窗口）、`frontend`（前端：`site/build.py`、九语文案、页面信息架构，唯一站点源码写者）、`release`（发布：生产构建 + `sync_r2.ps1` + `verify_live` + tag/Release，唯一 `site/dist` / R2 写者）。工位是可复用 teammate：**已存在就 `send_message` 唤醒，不要重复建同名**；没有就先建。
- **按需增减、不设上限（用户 2026-11-20 授权）**：出现**新的可并行工作**时，Lead **自主决定新建工位（临时或长期），不必请示、不设人数上限**；工作减少时自主收回，任务完成即退、不空养；没有并行工作就只用这 4 个。
- **构建与发布各归一个人（用户 2026-11-20 定）**：生产构建（`site/build.py` 写 `site/dist`）与上线（`sync_r2.ps1` + `verify_live` + tag/Release）**统一由 `release` 执行**；Lead 只验收与对外沟通，其它工位自验只能写 `SITE_OUT=.tmp/<名字>` 并贴命令。构建前先查 `rclone` / `python site/build.py` 没在跑，sync 与 build 不同时。
- 流程固定 6 步：取活 → 派单 → 实现 + 自验 → Lead 验收 → 构建发布 → 收尾。
- 硬规则：**工位不 commit / 不发布 / 不写 `site/dist`**；**Lead 不替工位写实现**（例外只有 P0 热修，且要在交接里写明原因）；**禁止 `wait_agent`**（派单 / 发消息后结束本轮，工位回报自动开新一轮）。
- 派单走共享任务（`team_task_create`，写清目标 / 验收 / 写权限 / 禁止项），回报 ≤200 字「改了什么 / 怎么验的 / 还剩什么」。
- 并行硬约束：`site/build.py` 源码同一时间只一个写者（`frontend` / 临时工位按 `write_scopes`）；`data/drugs.db` 同一时间只一个写窗口（`backend`）；构建与发布串行、均由 `release` 执行。

**谷段起止用一次性 `at` 提醒**（用户 2026-10-30 要求，**仅谷段交付会话**；对接会话禁止建任何 schedule）：开工时若当前时间早于 **08:20 北京**，用 `schedule_create` 建一条 at 提醒在当天 08:20 收尾（内容=核对版本/更新队列与交接/写状态表/≤200 字摘要/**停止，不再开新活**）；若当天 00:35 还没到就也建一条开工提醒。只建 at、不建 cron，收尾后自然消失。

## 3. 红线速查（不许越）

- 商品名不是主键，查询永远返回候选集。
- 只做身份对应 + 「不可互换」警示：**不给用药建议、不做剂量换算、不判断两药能否互换**（理由见 `docs/为什么不做替代推荐.md`）。
- 碰撞由 `collision` 视图自动推导，不手工标注。
- 不做 login；不付费买数据；不绕 WAF；不手工推 `gh-pages`；不提交 `data/*.db`、`site/dist/`、`.tmp/`、`.env`、`tools/`。
- 涉及花钱/删数据/改公开口径：写进报告等你看到，不擅自执行。
- **R2 Class A 免费 1M/月是硬预算**：单次发布 PUT 预计 >50k 需 Lead 批准；当月累计 >900k 停发布报人；**预计会超 1M（进入计费）必须先向用户申请，批准后才发，不得自行超支**；每次发布报告写 PUT/当月累计/占比。
