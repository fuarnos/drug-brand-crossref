- 商品名不是主键，查询永远返回候选集。
- 只做身份对应 + 「不可互换」警示：**不给用药建议、不做剂量换算、不判断两药能否互换**（理由见 `docs/为什么不做替代推荐.md`）。
- 碰撞由 `collision` 视图自动推导，不手工标注。
- 不做 login；不付费买数据；不绕 WAF；不手工推 `gh-pages`；不提交 `data/*.db`、`site/dist/`、`.tmp/`、`.env`、`tools/`。
