> 本站唯一的数据源许可登记处。新增数据源 / 数据源条款变化 / 发布任何批量数据前，**先改这里**，再改 About 与 ETL。

> 配套审计报告：`reports/license-audit.md`（缺口清单 + About 现状 + 三语署名建议）。

## 1. 结论分级（本站口径）

| 标记 | 含义 | 可做什么 |
|---|---|---|
| ✅ **可再发布** | 开放许可或公有领域（CC0 / CC BY / OGL / US Gov work / PDM） | 可存结构化字段、可在页面展示派生结果；**必须署名 + 许可链接** |
| 🟡 **条件性 / 待确认** | 有「署名后可引用」类条款，或非开放许可、或条款须复核 | 只展示**事实字段**（名称、成分、规格、状态、来源 URL）；不复制原文/整表；标「待确认」并每轮复核 |
| 🔴 **仅事实 + 链接** | 未找到再发布许可 / 明确禁止再分发 | 只存不可版权的事实字段 + 链回原文；**不再发布原始数据文件**；页面显式声明「未找到再发布许可」 |
| ⚪ **未接入** | 已调研但未进库，或明确不使用 | 不产生义务；接入前必须先把本行升级为 ✅/🟡/🔴 |

补充原则：
- **事实字段不转载正文**：所有来源统一只存名称/成分/规格/剂型/状态/编号等事实，不复制说明书、CMI、SmPC、PDF 全文。
- **非商业定位**：本站公开、无广告、无付费，属非商业性公开参考站；**若未来商业化（广告、赞助、收费 API/数据包），WHO INN（NC）、Health Canada DPD（非商业）、COFEPRIS（gob.mx 条款）等行必须重新评估**。
- **share-alike 传染**：标「SA」的来源（WHO INN = CC BY-NC-SA 3.0 IGO、ChEMBL = CC BY-SA 4.0）一旦进入派生数据库，**该派生映射表须以同许可公开**（提供导出或链接）。不要把它们与「内部对齐中间层」混在一起对外发布。
- **署名格式**：每个来源在 About「数据来源与覆盖」段给出「机构 + 数据集名 + 许可名 + 许可链接」；页面级引用保留每条记录的 `source_url`。

## 5. 维护流程（新来源 / 条款变化）

1. 先在本文件新增/修改一行，写清「许可结论 + 可再发布范围 + 义务 + 证据 URL」；
