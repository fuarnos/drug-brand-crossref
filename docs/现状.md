## 1. 这个站是什么

给一个名字（商品名 / 通用名 / 俗称 / 包装上一行字），**定位它是哪个药、什么规格**，再给出**其他国家的对应产品**。
静态站，单通道发布到 R2 主域 `https://drugcrossref.com/`；git 仓库只作源码备份。

**三条底线（不可违背，细则见 `AGENTS.md` §1）**

1. **商品名不是主键**：查询永远返回候选集，唯一性靠「国家 × 剂型 × 规格 × 活性成分」。
2. **碰撞自动推导**：`collision` 视图按成分数 / 释放机制分级，不手工标注（只有「品牌家族」是人工表）。
3. **不给用药建议**：只做身份对应 + 「不可互换」警示，**不做剂量换算、不判断能否互换**（`docs/为什么不做替代推荐.md`）。

## 5. 文档约定与归档规则

- **提炼不复制**：新文档写结论 + 出处（`queue 行号` / `reports/xxx.md`），单条 ≤80 字，不搬历史叙述。
- **数字现查**：README / About / CHANGELOG / 本页 / `coverage` 用同一组数，以 `data/drugs.db` 与 `site/dist` 现查为准。
- **交接归档**：`docs/交接-*.md` 只留最近 5 份在根目录；**早于 2026-11-20 的 17 份**已移到 `docs/archive/handover/`（2026-11-26 归档，`git mv`，**不删文件**）。以后每段收尾把超出 5 份的旧交接移入归档区。
- **报告索引**：`reports/INDEX.md` 由脚本扫描文件名 + 首标题 + 首条结论生成；新增报告无需手工改索引，重跑生成器即可（生成器为临时脚本，规则即本行）。
- **不写进 product_name**：俗称 / 旧名进 `nickname` 表，每条带出处。
- **失败与缺口也要写**：报告里写清失败项、未验证项与原因（`AGENTS.md` §8）。
