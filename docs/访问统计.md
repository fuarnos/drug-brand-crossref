# 访问统计（GoatCounter）

> 状态：2026-10-26 接入 v0.4.1。只做**后台看**，页面不公开任何计数。

## 1. 需求与边界

| 项 | 结论 |
|---|---|
| 看什么 | PV / 独立访客（按天去重）趋势、来源网站、国家/地区、浏览器、屏幕尺寸 |
| 事件 | 站内搜索词、结果点击、报告入口、更新日志、国家切换 |
| 公开显示 | **不做**，访客看不到任何计数 |
| 隐私 | cookieless、不记录个人数据、不用于广告；About 页三语说明 |
| 服务商 | GoatCounter（免费公开用量，开源，cookieless） |

## 2. 配置

站点码放在仓库根 `.env`（不入库）：

```
GOATCOUNTER_CODE=drug-brand-crossref
```

- 构建时 `site/build.py` 读环境变量或 `.env`；有值才在每页 `<head>` 注入：
  `<script data-goatcounter="https://<code>.goatcounter.com/count" async src="https://gc.zgo.at/count.js"></script>`
- 没有 `GOATCOUNTER_CODE` 时不注入，站点行为完全不变（本地/他人克隆不携带统计）。
- 后台：<https://drug-brand-crossref.goatcounter.com>
- 计数端点：`https://drug-brand-crossref.goatcounter.com/count`（由脚本自动调用）

## 3. 事件约定（GoatCounter custom events）

`event` 事件会出现在后台 events 列表；路径即事件名，不含用户标识。

| 事件 | 触发 | 备注 |
|---|---|---|
| `search-<term>` | 搜索框停止输入 900ms 后、归一化词长 ≥2 | 词截断 40 字符；不记录设备/身份 |
| `click-result` | 点击结果里的品牌/成分链接（`/name/…` 或 `/drug/…`） | 统计“搜到了且点进去” |
| `click-report` | 点击“报告这个结果”（GitHub Issue 链接） | 数据纠错入口 |
| `click-whatsnew` | 点击更新日志链接 | — |
| `country-<XX>` | 切换国家选择器 | `country-US` 等；清空时 `country-ALL` |

页面浏览（PV/UV）由 count.js 自动统计，不需要额外字段。

## 4. 看数据

1. 登录 <https://drug-brand-crossref.goatcounter.com>；
2. 首页看 PV/访客/来源/页面；顶部可选日期范围（今日/本周/月/自定义）；
3. `Events` 页看搜索词与点击；`Locations` 看国家；屏幕尺寸可推断手机/桌面；
4. 支持 CSV/JSON 导出（Settings → Export）。

## 5. 关闭 / 更换

- 关闭：删掉 `.env` 里的 `GOATCOUNTER_CODE`，重建并发布即可（脚本不再注入）；
- 更换服务：改 `site/build.py` 的 `GC_TAG` 注入段与 `APP_JS` 的 `gcEvent()`，重建发布。

## 6. 注意

- 广告拦截插件可能拦截 `gc.zgo.at`，被拦的访问不计入；统计是估算不是精确审计。
- GoatCounter 不做 cookie 会话，UV 是按天去重的近似值。
- 不要把 GoatCounter 的 code 当成秘密（它本来就在公开页面源码里），真正的凭据是登录账号。
