# 手机通道：手机看进度 + 发指令（设计）

日期：2026-10-26　状态：已实施（同一日验证通过，验收结果见 [手机通道.md](手机通道.md) 与 `reports/2026-10-26-手机通道.md`）
相关：`AGENTS.md`、`render_dashboard.py`、`serve.py`

## 1. 要解决的问题

人不在电脑前（手机 / 4G），需要两件事：

1. **看进度**：数据量、站点构建状态、仓库状态、最近报告、指令处理情况；
2. **发指令**：用手机写一句话下达下一步，**不要求 agent 此刻在线**；agent 下次开工读取、执行、回帖。

明确不做：不给用药建议、不碰 `data/drugs.db` 的写路径、不做实时对话、不替代 DSH 会话界面。

## 2. 形态

一个**独立于站点**的手机网页 + 一个 append-only 指令队列。

```
手机浏览器 ──HTTP(S)──> mobile/server.py（本机 python，绑 0.0.0.0:8787）
                          ├── /            手机页面（内联 HTML/CSS/JS，无外链）
                          ├── /api/state   进度 + 队列 JSON（20 秒缓存）
                          ├── /api/command 追加一条指令
                          └── /healthz     隧道探活（免 token）
                                    │
                                    ├── 读：data/drugs.db（只读）、site/dist、git、reports/
                                    └── 写：inbox/commands.jsonl、inbox/replies.jsonl（append-only）
```

- **局域网**：`http://<电脑内网 IP>:8787/?k=<token>`，手机同 Wi-Fi 直接开，可存书签。
- **4G / 外网**：`--tunnel` 起 cloudflared quick tunnel，拿到 `https://xxx.trycloudflare.com`；
  URL 每次启动会变，进程常驻期间稳定。备选 `ssh -R`（localhost.run，无需下载）。
- 隧道是**公网可解析地址**，所以必须有 token；没有 token 一律 401，不泄露任何信息。

## 3. 队列设计（append-only，两份文件）

`inbox/commands.jsonl`——只追加，不修改历史行：

```json
{"id":"c-20261026-194512-a3f1","ts":"2026-10-26T19:45:12-07:00","text":"把墨西哥浓度复核补完","source":"phone","ua":"iPhone Safari"}
```

`inbox/replies.jsonl`——agent 或人回帖，也只追加：

```json
{"id":"r-20261026-200000-9c2e","cmd":"c-20261026-194512-a3f1","ts":"2026-10-26T20:00:00-07:00","status":"done","text":"已重跑 MX 入库，见 reports/mx-*.md","source":"agent"}
```

**状态是推导出来的，不落库**：某条指令的 `status` = 它最后一条回帖的 `status`，没有回帖就是 `pending`。
`STATUSES = ("pending", "doing", "done", "blocked")`。

并发：本机多进程同时写要加锁（`inbox/.lock`，`O_CREAT|O_EXCL` 自旋，超时 5 秒）。

## 4. 对外接口（跨文件契约，实现方必须照抄）

### 4.1 `mobile/queue.py`（工位 B 负责）

```python
INBOX_DIR: Path                      # 默认 <repo>/inbox；环境变量 MOBILE_INBOX 可覆盖（测试用）
STATUSES: tuple[str, ...] = ("pending", "doing", "done", "blocked")

def ensure_dirs() -> None: ...
def append_command(text: str, *, source: str = "phone", ua: str = "") -> dict: ...
def append_reply(cmd_id: str, status: str, text: str, *, source: str = "agent") -> dict: ...
def load_state() -> dict: ...
```

`load_state()` 返回：

```json
{
  "commands": [
    {"id": "c-...", "ts": "...", "text": "...", "source": "phone", "ua": "...",
     "status": "done",
     "replies": [{"id": "r-...", "ts": "...", "status": "done", "text": "...", "source": "agent"}]}
  ],
  "counts": {"total": 3, "pending": 1, "doing": 0, "done": 2, "blocked": 0}
}
```

- `commands` 按 `ts` 升序（最新在最后）；`replies` 同序。
- 坏行（JSON 解析失败）跳过并在日志里 `print` 一行警告，不能整页 500。
- `append_command` 返回完整记录（含 `id` / `ts` / `source` / `ua`）；`text` 去首尾空白，空文本抛 `ValueError`，超 2000 字抛 `ValueError`。
- `append_reply` 校验 `status in STATUSES`、`cmd_id` 存在，否则 `ValueError`。

### 4.2 `mobile/page.py`（工位 A 负责）

```python
def render_index(version: str, now: str) -> str: ...   # 完整单页 HTML
def render_denied() -> str: ...                        # 401 页
```

硬约束：无任何外部请求（不引 CDN/字体/图标）、`<meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover">`、320–480 px 无横向滚动、输入框 `font-size:16px`、按钮高 ≥44 px、中文字体栈、暗色可选但默认自动。

### 4.3 `mobile/server.py`（工位 A 负责）

```
GET  /               200 页面（需 token）｜401 render_denied()
GET  /api/state      200 {"ok":true,"queue":...,"progress":{...},"server":{...}}（需 token）
POST /api/command    body {"text":"..."} → 201 {"ok":true,"id":"c-..."}（需 token）
GET  /healthz       200 "ok"（免 token）
其他路径             404
```

**token**：`?k=<token>` 或 cookie `mb_token`；首次带 `?k=` 命中后 `Set-Cookie`（`HttpOnly; SameSite=Lax; Path=/; Max-Age=2592000`）并 302 到 `/`。
token 来源：`--token` 参数 > 环境变量 `MOBILE_TOKEN` > `.tmp/mobile/token.txt` > 自动生成（`secrets.token_urlsafe(18)`）并写入该文件。
`.tmp/` 已在 `.gitignore`，token 不进仓库。

**限流**：同 IP 每分钟最多 20 次 POST，超出 429；单条正文上限 2000 字。

**`progress` 结构**（数字一律现查，不抄旧数）：

```json
{
  "db":    {"total": 0, "subst": 0, "keys": 0, "named": 0, "severe": 0, "warn": 0, "info": 0,
            "US": 0, "GB": 0, "CN": 0, "ES": 0, "MX": 0, "AU": 0, "CA": 0},
  "site":  {"built_at": "2026-10-26 19:00", "files": 0, "index_mb": 0.0, "drug": 0, "name": 0,
            "age_min": 12, "building": false},
  "repo":  {"branch": "main", "head": "153a7f1 2026-10-26 Add AGENTS.md…", "dirty": 1,
            "version": "v0.4.0", "version_date": "2026-10-26"},
  "reports": [{"name": "search-p0-fix.md", "mtime": "2026-10-26 18:02"}],
  "ts": "2026-10-26 19:45:12"
}
```

- `db` / `site` 直接复用 `render_dashboard.db_stats()` 与 `dist_stats()`（`sys.path` 插仓库根后 `from render_dashboard import ...`），保证与看板同一口径。
- `repo` 用 `tools/git/cmd/git.exe`（找不到再退回 PATH 的 `git`），失败时字段填空串/`null`，不能抛异常。
- `version` 从 `CHANGELOG.md` 第一条 `## vX — YYYY-MM-DD` 解析（参考 `site/build.py::_read_latest_release`）。
- `site.building`：`site/dist/index.html` 的 mtime 在 90 秒内视为「可能正在构建」。
- **进度不在请求里同步算**（实测 `db_stats()` 7.0 秒、`dist_stats()` 4.9 秒）：改为磁盘快照
  `.tmp/mobile/progress.json`（`computed_at` + `db_mtime` + `dist_mtime` + `payload`，原子写）
  + 后台 daemon 线程（启动算一次，之后每 60 秒查 mtime，变了才重算，`?fresh=1` 强制重算）。
  `/api/state` 只读内存快照，永远 < 300 ms；没有快照时返回 `warming: true`、`progress: null`，
  页面显示「正在统计数据…」并在 3 秒后重试。响应带 `computed_at` / `stale`（>10 分钟）/ `refreshing`。
  因此 git 状态与 `reports/` 列表也只在重算时更新——要立刻看新的就点「刷新」。

**服务入口**：`make_server(host, port, token) -> ThreadingHTTPServer` 供测试直接起在 `127.0.0.1:0`；`main()` 解析 `--host`（默认 `0.0.0.0`）、`--port`（默认 8787）、`--open`、`--tunnel`、`--token`，启动时打印内网地址 + 带 token 的完整链接。
`--tunnel` 调 `mobile/tunnel.py`（Lead 负责，接口见下）。

## 6. 验收

1. `& $py -m unittest tests.test_mobile_inbox -v` 全绿（队列 + 端点 + token + 限流 + 坏行）。
2. `& $py mobile/server.py --port 8787` 起服务后：
   - 无 token → 401；带 `?k=` → 200 且拿到 cookie；
   - `POST /api/command` → `/api/state` 里出现该条且 `status=pending`；
   - `mobile/inbox.py pending` 能看到同一条；`mobile/inbox.py done <id> "..."` 后页面变 `done` 并显示回帖。
3. 页面在 360×800 视口无横向滚动（headless Chrome 截图核对）。
4. `--tunnel` 起 cloudflared，手机能打开公网 URL（真机验；沙箱内至少验证 tunnel 进程与 URL 解析）。
5. 不碰 `data/drugs.db` 写路径；`site/build.py` 与 `publish.ps1` 的并行纪律不受影响（新服务只读 dist）。

## 7. 已知缺口

- 快速隧道 URL 每次重启都变，长期稳定需要命名隧道（Cloudflare 账号）或 Tailscale；文档写明。
- 「构建跑到哪一步」拿不到：`site/build.py` 不写日志文件，页面只能显示 dist 时间与「可能正在构建」。
- 手机发来的指令是**人的话**，agent 执行前若涉及删数据 / 发布 / 花钱，仍按 AGENTS.md §6/§9 回来问人，不自动执行。
