# FOI 申请草稿：ARTG 药品条目批量导出

> 用途：向澳洲卫生部（TGA 所属部门）申请 ARTG 现行药品条目的机器可读导出。
> 递交前把 `[你的姓名]`、`[邮箱]`、`[日期]` 填上；英文正文可直接用。

## 递交信息（2026-10 核对）

- 收件方：TGA FOI Coordinator（Therapeutic Goods Administration，Department of Health, Disability and Ageing）
- 在线表单：https://www.tga.gov.au/resources/resources/forms/freedom-information-request-form
- 邮箱：tga.foi@health.gov.au（电话 1800 020 653 / 02 6289 4630）
- 法律依据：*Freedom of Information Act 1982* (Cth)
- **费用：无申请费**；处理可能产生 processing charges（检索 $15/小时、决定前 5 小时免费、之后 $20/小时）。可在申请里以「非商业公共利益」申请减免，TGA 会给书面估价后再决定。
- 时限：14 天内确认收到；30 个日历日内决定（复杂/量大可延期，也可能来信要求缩小范围）
- 注意：TGA 网站对程序化访问返回 403（Akamai），请**用浏览器或邮箱人工提交**，不要用脚本刷。

## 提交前只需填三处

把正文里的 `[你的姓名]`、`[邮箱]`、`[日期]` 替换掉即可；其余英文可直接复制。

## 英文正文

Dear FOI Officer,

I make this request under the Freedom of Information Act 1982 (Cth). This is an
application for the purposes of the FOI Act.

**Contact.** Please reply by email to [邮箱]. My name is [你的姓名].
[Optional postal address: 你的邮寄地址]

**Scope.** I request access to documents containing, in machine-readable form, the
current entries on the Australian Register of Therapeutic Goods (ARTG) for **medicines
only** (not medical devices). Specifically, the following fields for each current
medicine entry:

1. ARTG ID
2. ARTG name / product name
3. Sponsor (responsible person)
4. Active ingredient(s)
5. Dosage form
6. Strength
7. Registration status and, if applicable, the date the entry ceased to be current
8. Whether the medicine is prescription, pharmacist-only or OTC (if recorded)

**Format.** I do not seek paper copies or a printout of individual entries. I ask for
the data in whatever machine-readable form the Department holds it (CSV, Excel,
database export, delimited text or XML). If the Department holds the data in a
database used to generate the public ARTG search, an export of that table is what I am
asking for.

**Public interest.** The information is already published entry-by-entry on the ARTG
public search. This request is for the same facts as a single compilation, to build a
non-commercial public reference that maps brand names to active ingredients across
countries (the site is public, ad-free, and carries source attribution). I ask that
any charges be waived on public interest grounds under the FOI Charges Determination.

**If refused in part.** If any field is claimed exempt, please release the remainder
and identify the provision relied on.

Yours sincerely,
[你的姓名]
[邮箱]
[日期]

## 中文要点（自己留底）

- 只要**药品**，不要器械；只要 8 个字段，不要工艺/配方细节——降低「商业机密」和
  「实务拒绝」的风险。
- 明确「不要逐条打印件，只要一份机器可读导出」——这是绕开「信息已公开可查」的关键。
- 公共健康 + 非商业 + 会署名，是申请免收费的理由。
- 法定 30 天答复；可能先来一封 s 24AB 协商信（要求缩小范围），收到后按信里要求回，
  不要不回。

## 预期
