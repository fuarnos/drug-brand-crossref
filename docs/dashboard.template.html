05

剩余风险

按「会不会影响用户」排序

首屏索引 {{INDEX_MB}} MB 中高

检索索引一次拉全量，手机 4G 首搜会明显等。计划按首字母拆片 + 压缩，或改成轻量服务端查询。

墨西哥规格 29% · 中国商品名键 {{CN_TRADE}} 中高

COFEPRIS 源数据没有浓度列，能回填的已回填；中国公开入口只给公示批次、商品名有值很少。页面上都标注了「查不到 ≠ 不存在」，但覆盖仍是已知上限。

剂量对应只做到 D1 中

{{SUBST}} 个成分里只有 {{ATC}} 个有 ATC；D2 盐基折算（base_fraction 仍是默认 1.0）与 D3 不可互换判定未实现，/warn 页也没做。

部分许可没落纸 中

CIMA 逐条 REST、COFEPRIS 目录采样、中国医保库都没写「可批量再发布」；公开页已署名并链回原文，商业使用前需要书面依据。AU 的 ARTG 全量仍只能走 FOI（草稿已写，未递交）。

站点体积 {{SIZE_MB}} MB / {{FILES}} 文件 中低

GitHub Pages 单站上限 1 GB，目前仍在半程内；每次发布要复制/推送 3 万文件，耗时主要在文件数。
