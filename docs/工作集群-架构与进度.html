05

剩余风险

按「会不会影响用户」排序

首搜索引 3.9 MB（raw 32.2 MB） 中高

v0.3.4 起首屏不拉索引（17 KB），v0.4.0 又把首搜从 6.06 MB 压到 3.86 MB（列式 + 字典）；v0.5.1 改为 manifest + 分片，首搜 3.78 MB → 约 254 KB gz（拼音表 0.41 MB 仍按需懒加载）。下一步：停掉 index.json 双写（省 ~35 MB）并细化分片。

墨西哥规格 34.1% · 中国商品名键 4,866 中高

COFEPRIS 源数据没有浓度列，能回填的已回填；中国公开入口只给公示批次、商品名有值很少。页面上都标注了「查不到 ≠ 不存在」，但覆盖仍是已知上限。

剂量对应只做到 D1 中

12,649 个成分里只有 6,021 个有 ATC；D2 盐基折算（base_fraction 仍是默认 1.0）与 D3 不可互换判定未实现，/warn 页也没做。

部分许可没落纸 中

CIMA 逐条 REST、COFEPRIS 目录采样、中国医保库都没写「可批量再发布」；公开页已署名并链回原文，商业使用前需要书面依据。AU 的 ARTG 全量仍只能走 FOI（草稿已写，未递交）。

站点体积 436.3 MB / 60,375 文件 中低

GitHub Pages 单站上限 1 GB，目前仍在半程内；每次发布要复制/推送 3 万文件，耗时主要在文件数。

三语译文与许可段落未经母语抽检 中低

About / What's new 与 /warn 的西语正文为 AI 翻译，许可段为三语并列。上线不受影响，但对外正式引用前建议母语抽检；ES/MX 用词差异只影响语感。
